# 🏛️ 게임 기획서: <대한민국 대통령: 외교의 신>

## 1. 기본 배경 & 자유로운 전개

* **시작 상황:** 2026년 8월, 미국 트럼프 대통령의 "한국산 전 품목 관세 50% 기습 인상" 선언으로 시작.
* **자유로운 세계관:** 미·한 관계에만 국한되지 않음. 플레이어의 선택에 따라 중국(시진핑), 일본, 북한, 러시아 등 주변국이 개입하거나 예상치 못한 국제적 연쇄 반응(미사일 발사, 비밀 협상 등)이 얼마든지 일어날 수 있음.
* **대화 및 생생한 연출 허용:** 건조한 보고서에 그치지 않고 각국 정상이나 인물의 인상적인 대화(" ")와 생동감 있는 상황 묘사를 포함하여 극적인 재미를 높임.
* **템포감:** 한 턴의 분량은 1~3문장으로 짧고 임팩트 있게 구성해, 플레이어가 빠르게 다음 선택을 이어가는 속도감 있는 진행을 지향함.

## 2. 게임 시스템 (수치 관리)

* 게임 내 3대 지표: `지지율`, `경제`, `정치력` (초기값 각각 50).
* 지표 중 하나라도 0 이하가 되면 게임오버 — 그 턴 AI가 서술한 상황을 그대로 극적인 엔딩으로 사용 (탄핵, 국가부도, 지지율 붕괴 등 별도의 엔딩 연출 없이도 몰입감 있는 결말이 되도록 설계).

## 3. 토큰 최적화 및 유연한 응답 구조

* 대화 기록 누적으로 인한 토큰 폭탄을 막기 위해, 백엔드는 과거 대화 전체를 저장하지 않음 (스테이트리스 서버).
* 프론트엔드가 [현재 지표 + 직전 AI 상황 + 사용자의 현재 지시]만 백엔드로 넘겨 토큰 사용량을 항상 일정하게(최저 수준) 유지.
* 첫 상황(트럼프 관세 발표)은 API 호출 없이 프론트엔드에 고정 텍스트로 미리 심어두어, 게임 시작 시 불필요한 토큰 소모를 없앰.
* AI의 응답은 **1~3문장으로 짧고 몰입감 있게 출력**.
* 답변 마지막 줄의 지표 변화는 매번 필수로 나올 필요는 없으며, **의미 있는 수치 변화가 발생했을 때만** 선택적으로 `[지표변화: 지지율(+-N), 경제(+-N), 정치력(+-N)]` 형태로 포함되도록 함.

## 4. 안정성 요구사항

* 사용자가 값을 입력하고 전송하면 화면에 AI 응답이 표시되어야 함.
* 응답을 기다리는 동안 사용자가 진행 상황을 알 수 있어야 함 (로딩 표시, 입력창/버튼 비활성화).
* 빈 값을 전송해도 서버가 오류로 죽지 않고 정상적인 안내 응답을 반환해야 함.
* 동일한 요청을 짧은 시간에 두 번 보내도 서버가 오류를 내지 않아야 함 (스테이트리스 구조 + 예외 처리로 보장).

## 💻 기술 스택 및 개발 요구사항

### 0. 폴더 구조

```
portfolio/
├── main.py        # FastAPI 백엔드 (정적 페이지 서빙 + /api/turn 엔드포인트)
├── index.html     # 프론트엔드 단일 페이지 (UI + JS 로직 포함)
├── .env           # GEMINI_API_KEY 보관 (git에는 커밋되지 않음)
└── .gitignore     # .env 제외 설정
```

### 1. 실행 방법

```bash
pip install -r requirements.txt
```

`.env` 파일에 아래 내용 작성:

```
GEMINI_API_KEY=발급받은_API_키
```

서버 실행:

```bash
python -m uvicorn main:app --port 8000
```

브라우저에서 `http://127.0.0.1:8000` 접속.

### 2. 백엔드 (Python / FastAPI)

* 구글 공식 SDK인 `google-genai` 사용 (`pip install google-genai fastapi uvicorn python-dotenv`).
* 모델: `gemini-3.5-flash` 사용 (속도 및 비용 최적화).
* `systemInstruction`을 활용해 연출 톤앤매너와 지표 출력 규칙 설정.
* 엔드포인트: `GET /` (정적 프론트엔드 서빙), `POST /api/turn` (프론트엔드에서 현재 지표와 사용자의 지시를 받아 Gemini 호출 후 응답 반환).
* API 키는 `.env`의 `GEMINI_API_KEY`에서 로드 (로컬 실행 전용, 저장소에는 커밋하지 않음).

### 3. 프론트엔드 (단일 HTML 파일 - `index.html`)

* FastAPI가 `GET /`에서 직접 서빙.
* **UI 구성:**
  - 상단: 3개 지표(지지율, 경제, 정치력) 현황 바 및 숫자로 표시.
  - 중앙: 청와대 상황실/속보 화면 느낌의 모던한 텍스트 챗 윈도우.
  - 하단: 대통령의 지시를 자유롭게 적을 수 있는 텍스트 Input 및 전송 버튼.
* **JS 로직:**
  - AI 답변 텍스트 중 `[지표변화: ...]` 패턴이 발견되면 정규식(Regex)으로 파싱하여 화면 상단 지표를 즉시 업데이트하고 해당 태그 문자열은 화면 출력에서 깔끔하게 제거.
  - 지표 변화 태그가 없는 답변일 경우 상태값을 그대로 유지.
  - 요청 전송 중에는 로딩 메시지를 표시하고 입력창/버튼을 비활성화하여 중복 전송을 방지.
  - 빈 입력은 프론트엔드에서 1차로 걸러내고, 서버에서도 2차로 안전하게 처리.
  - 지표가 0 이하가 되면 입력창 비활성화 및 재시작 버튼 띄우기.

### 4. API 명세

**`POST /api/turn`**

요청 (Request Body):

```json
{
  "stats": { "지지율": 50, "경제": 50, "정치력": 50 },
  "lastSituation": "직전 턴에 표시된 AI 상황 서술 텍스트",
  "userInput": "플레이어(대통령)가 입력한 지시"
}
```

응답 (Response Body):

```json
{
  "text": "AI가 생성한 상황 서술 (1~3문장) + 선택적으로 [지표변화: ...] 태그"
}
```

* `userInput`이 빈 문자열이면 Gemini를 호출하지 않고 안내 문구를 즉시 반환함 (토큰 절약 + 안정성).
* Gemini 호출 중 예외가 발생해도 500 에러 대신 `{"text": "..."}` 형태의 정상 응답으로 감싸서 반환함 (프론트엔드가 항상 동일한 형태로 처리 가능).
