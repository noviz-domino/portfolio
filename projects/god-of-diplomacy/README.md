# 🏛️ 대한민국 대통령: 외교의 신 (God of Diplomacy)

Gemini API를 활용한 텍스트 기반 정치·외교 롤플레잉 게임.
플레이어는 2026년 8월 대한민국 대통령이 되어, 미국의 기습 관세 폭탄으로 시작되는 국제 위기를 자유롭게 헤쳐나간다.

## 게임 소개

2026년 8월, 트럼프 대통령이 한국산 전 품목에 관세 50% 인상을 선언한다.
플레이어가 내리는 모든 지시는 AI가 실시간으로 해석해, 주변국 정상의 반응과 예상치 못한 국제정세 연쇄 반응으로 이어진다.

- **자유로운 지시** — 선택지가 아니라 자연어로 원하는 대책을 직접 입력한다.
- **3대 국정 지표** — `지지율` / `경제` / `정치력` (초기값 각 50). 하나라도 0 이하가 되면 게임오버.
- **열린 세계관** — 미·한 관계에 국한되지 않고 중국, 일본, 북한, 러시아까지 개입할 수 있다.

## 실행 방법

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. API 키 설정

[Google AI Studio](https://aistudio.google.com/api-keys)에서 API 키를 발급받은 뒤, `.env.example`을 `.env`로 복사하고 키를 입력한다.

```
GEMINI_API_KEY=발급받은_API_키
```

### 3. 서버 실행

```bash
python -m uvicorn main:app --port 8000
```

브라우저에서 `http://127.0.0.1:8000` 접속.

## 설계 포인트

### 토큰 사용량을 턴 수와 무관하게 일정하게 유지

대화 기록이 누적되면 토큰 사용량이 턴마다 불어난다. 이를 막기 위해 **백엔드를 스테이트리스로 설계**했다.

매 턴 프론트엔드가 `{현재 지표, 직전 AI 상황, 사용자 지시}`만 전달하므로, 100턴을 진행해도 요청 크기가 첫 턴과 동일하다.
게임 시작 화면(관세 선언)도 API 호출 없이 프론트엔드에 고정 텍스트로 심어 불필요한 호출을 제거했다.

### 지표 변화를 응답 텍스트에서 파싱

AI가 서술과 수치를 한 번의 호출로 함께 생성하도록 하고, 응답 끝에 붙는 태그를 정규식으로 파싱한다.

```
[지표변화: 지지율(+4), 경제(-2), 정치력(+5)]
```

파싱 후 태그 문자열은 화면 출력에서 제거해, 플레이어에게는 자연스러운 서술만 보인다.
의미 있는 변화가 없는 턴에는 태그 자체가 생략되도록 해 불필요한 수치 변동을 막았다.

### API 키 보호

프론트엔드에서 Gemini를 직접 호출하면 API 키가 브라우저 코드에 노출된다.
따라서 **키는 서버 프로세스 안에서만 `.env`로부터 로드**하고, 브라우저는 자체 백엔드(`/api/turn`)에만 요청을 보낸다.

### 안정성 처리

- 빈 입력은 프론트엔드에서 1차 차단하고, 서버에서도 Gemini 호출 전에 2차 검증한다.
- Gemini 호출 예외는 `try/except`로 감싸 500 에러 대신 정상 응답 형태로 반환한다.
- 요청 처리 중에는 로딩 메시지 표시와 함께 입력창·버튼을 비활성화해 중복 전송을 막는다.

## API

**`POST /api/turn`**

```json
// Request
{
  "stats": { "지지율": 50, "경제": 50, "정치력": 50 },
  "lastSituation": "직전 턴에 표시된 상황 서술",
  "userInput": "플레이어가 입력한 지시"
}

// Response
{
  "text": "AI가 생성한 상황 서술 + 선택적 [지표변화: ...] 태그"
}
```
