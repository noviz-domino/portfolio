# 대한민국 대통령: 외교의 신

Gemini API 기반 텍스트 정치/외교 롤플레잉 게임. FastAPI 백엔드 + 정적 HTML/JS 프론트엔드.

## 실행 방법

```bash
py -3.14 -m uvicorn main:app --port 8000
```

브라우저에서 `http://127.0.0.1:8000` 접속. `.env`에 `GEMINI_API_KEY`가 있어야 정상 동작함 (없으면 API 호출 부분에서 오류 메시지를 반환하지만 서버가 죽지는 않음).

## 파일 구조

- `main.py` — FastAPI 서버. `GET /`에서 `index.html` 서빙, `POST /api/turn`에서 Gemini 호출
- `index.html` — 단일 페이지 프론트엔드. 상단 지표바, 중앙 채팅 로그, 하단 입력창
- `.env` — `GEMINI_API_KEY` 보관 (gitignore 처리됨, 커밋 안 됨)

## 게임 설계

- **시작 상황**: 2026년 8월, 트럼프 대통령의 한국산 전 품목 관세 50% 인상 선언 (프론트엔드에 하드코딩, API 호출 없이 바로 표시)
- **지표 3개**: 지지율 / 경제 / 정치력 (초기값 각 50). 원래 기획에는 한미동맹도 있었으나 사용자 요청으로 제거함
- **게임오버**: 지표 중 하나라도 0 이하가 되면, 그 턴의 AI 응답 텍스트를 그대로 결말로 사용 (별도 엔딩 API 호출 없음)
- **토큰 절약**: 백엔드는 대화 기록을 저장하지 않음(스테이트리스). 매 턴 프론트엔드가 `{현재 지표, 직전 AI 상황, 사용자 지시}`만 전달 → 브라우저 새로고침하면 진행 상황 초기화됨 (의도된 동작)
- **응답 길이**: 1~3문장으로 제한 (원래 3~5문장이었으나 토큰 절약을 위해 축소)
- **모델**: `gemini-3.5-flash`
- **지표 변화 파싱**: AI 응답 끝에 `[지표변화: 지지율(+N), 경제(+N), 정치력(+N)]` 형태가 있으면 정규식으로 파싱 후 화면 반영, 태그 문자열은 화면에서 제거. 값 변화가 없으면 태그 자체가 생략될 수 있음(선택적)

## 검증된 요구사항

- 입력값 전송 → AI 응답 화면 표시 ✅
- 응답 대기 중 로딩 표시(`📡 상황실이 대응 방안을 분석하고 있습니다...`) + 입력창/버튼 비활성화 ✅
- 빈 값 전송 시 서버가 죽지 않고 안내 메시지 반환 (`main.py`의 `turn()`에서 빈 문자열 체크) ✅
- 동시에 같은 요청 2번 보내도 에러 없음 — 백엔드가 스테이트리스라 공유 상태 충돌이 없고, `try/except`로 API 에러도 죽지 않고 텍스트로 반환 ✅

## 보류/제외된 기능

- **정상 사진 표시 기능**: 실존 정치인 사진을 자동으로 검색/다운로드하는 건 저작권 문제로 보류. 사용자가 직접 사진 파일을 폴더에 넣어주면 파싱+표시 로직을 추가하기로 함 (아직 사진 파일 미제공, 기능 미구현)
