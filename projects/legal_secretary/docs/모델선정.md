# 모델 선정

2026-09 시점 조사 결과와 후보군. **최종 선택은 04단계 벤치마크 실측으로 확정**한다.
현 구조에서 세 모델 모두 환경변수로 교체 가능하므로 코드 변경 없이 바꿔 끼울 수 있다.

## 제약

배포 대상은 Oracle Cloud Always Free ARM Ampere A1 (4 OCPU / 24GB / GPU 없음)이다.

- 생성 모델은 8B 이하 + 양자화라야 실용적
- 임베딩·리랭커·웹앱이 같은 인스턴스에 함께 올라감
- 같은 품질이면 작은 모델이 유리
- 개발·벤치마크는 RTX 4060 노트북(8GB VRAM)에서 병행

라이선스도 제약이다. 공개 데모로 띄울 예정이므로 **상업적 이용이 가능한
라이선스**여야 한다.

## 생성 모델

### 후보

| 모델 | 크기 | 라이선스 | GGUF | 비고 |
|---|---|---|---|---|
| SKT A.X-4.0-Light | 7B | Apache 2.0 | 있음 | 한국어 특화 토크나이저 |
| 카카오 Kanana-1.5-8B-instruct | 8B | Apache 2.0 | 있음 | 다양한 양자화 배포 |
| Qwen3-8B | 8B | Apache 2.0 | Ollama 공식 | 한국어 정량 지표 미확인 |

### 제외

**LG EXAONE 4.0** — 두 가지 이유로 제외한다.
1. 32B와 1.2B만 존재하고 **8B 라인업이 없다.** 32B는 이 하드웨어에서 불가.
2. 라이선스가 `EXAONE AI Model License 1.2-NC`로 **비상업(NC)** 이다. 공개
   데모에는 부적합하다.

**네이버 HyperCLOVA X SEED** — 전용 라이선스의 상업적 이용 조건을 확정하지
못했다. 사용을 검토한다면 1차 라이선스 문서를 직접 확인해야 한다.

### 구버전 대비

v1이 쓰던 `benedict/linkbricks-llama3.1-korean:8b`는 Llama 3.1(2024년 중반)
기반이다. 당시에는 한국어 오픈 모델 선택지가 적어 불가피했으나, 이후 한국어를
처음부터 겨냥한 모델들이 나왔으므로 교체 대상이다.

## 임베딩

### KURE-v2 (고려대 nlpai-lab)

MTEB 한국어 검색 9개 과제 평균 nDCG@10 0.8160으로 상위. MIT 라이선스.
한국어 전용이나 본 프로젝트는 한국어 법률 문서 전용이라 문제되지 않는다.

**중요한 제약** — KURE-v2는 late-interaction(멀티벡터, MaxSim) 방식이다.
현재의 Chroma 단일벡터 파이프라인에 **드롭인 교체가 불가능**하며 인덱싱 구조를
바꿔야 한다.

### 판단

| 선택지 | 성능 | 이식 비용 |
|---|---|---|
| bge-m3 유지 | 기준선 | 0 |
| KURE-v1 | bge-m3 상회(주장) | 낮음 (단일벡터, 드롭인) |
| KURE-v2 | 최상위(주장) | 높음 (인덱싱 구조 변경) |

**KURE-v1을 우선 비교 대상으로 삼는다.** v2는 v1과 bge-m3의 실측 격차를 본 뒤
구조 변경을 감수할 가치가 있는지 판단한다.

Qwen3-Embedding(8B)은 다국어 리더보드 상위이나 한국어 전용 수치를 확인하지
못했고, 8B는 CPU 추론 부담이 커서 이 환경에 부적합할 가능성이 높다.

## 리랭커

**현행 `BAAI/bge-reranker-v2-m3` 유지.**

`Qwen3-Reranker-0.6B`(Apache 2.0, GGUF 배포, 유사 크기)가 대안이나, 한국어
성능 우위를 보이는 실측 근거를 찾지 못했다. 근거 없이 교체하지 않는다.
04단계에서 자체 데이터로 A/B 비교한 뒤 결정한다.

bge-reranker-v2-gemma 계열은 품질은 높으나 gemma-2B~9B 기반이라 CPU 환경에
부적합하다.

---

## 04단계 평가에 반영할 것

조사 중 한국어 법률 도메인 평가 자료를 확인했다. 평가셋을 맨땅에서 만드는 대신
이들을 활용하거나 참고한다.

- **KBL** — Korean Benchmark for Legal Language Understanding (arXiv:2410.08731).
  법률 언어 이해 벤치마크
- **Allganize RAG 리더보드** — 금융·공공·의료·**법률**·커머스 5개 도메인의
  한국어 RAG 평가 데이터셋. HuggingFace 공개

두 자료의 실제 내용과 최신 모델 점수표는 아직 확인하지 못했다. 04단계 착수 시
직접 열람해 활용 가능 여부를 판단한다.

---

## 근거의 한계

이 문서의 성능 주장 상당수가 뉴스 기사·블로그 등 2차 출처에 기반한다. 조사
과정에서 다음을 확인하지 못했다.

- A.X-4.0-Light, Qwen3-8B, HyperCLOVA X SEED 8B의 **한국어 법률 도메인 정량
  벤치마크**
- KURE-v1과 v2의 정확한 수치 비교 (1차 출처)
- Kanana-2가 8B dense 모델을 포함하는지, MoE 구조가 CPU 추론에 적합한지

따라서 **이 문서는 후보를 좁히는 용도이며, 선택의 근거가 아니다.** 실제 선택은
04단계에서 자체 법령 QA 셋으로 측정해 확정한다.
