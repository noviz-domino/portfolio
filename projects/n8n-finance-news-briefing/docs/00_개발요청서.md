# 프로젝트 2 개발 요청서 :: 금융 뉴스 브리핑 Agent

---


## 1. 배경과 목적

자산운용사의 리서치팀에서 개발 요청서가 들어왔습니다.

팀원들은 매일 아침 출근 전 여러 뉴스 사이트를 돌아다니며 시장 관련 기사를 찾아 읽습니다. 여기에는 세 가지 문제가 있습니다.
 
1. 사람마다 보는 매체가 달라 같은 팀인데도 아는 뉴스가 제각각입니다.
 
2. 기사 대부분은 연예나 스포츠라 금융 관련 기사를 골라내는 데만 시간이 듭니다.
 
3. 어제 읽은 기사를 오늘 또 읽는 일이 반복됩니다.

이 프로젝트는 **매일 아침 8시 30분, 여러 매체의 뉴스 중 금융 관련 기사만 골라 요약한 브리핑을 자동 발송하는 시스템**을 만듭니다. 팀원은 한 번만 확인하면 됩니다.

## 2. 시스템 구성

1. 각자 **본인 소유의 구글 시트**를 만들어 사용하고, **디스코드**는 개인 채널을 사용합니다.

```
⏰ 매일 아침 8시 30분 (자동 실행)
            │
            ▼
┌───────────────────────┐
│       RSS 수집         │
│   피드 A + 피드 B ...   │
└───────────────────────┘
            │
            ▼
┌───────────────────────┐
│        n8n            │
│                       │
│  1. 오늘 기사만 추림    │
│  2. 발송 이력 대조      │  <──── Google Sheet
│     (중복 제거)        │       (발송 이력)
│  3. 금융 키워드 필터    │
│  4. LLM 요약 + 중요도  │
│  5. 검증 안전판        │
│  6. 한 통으로 합치기    │
└───────────────────────┘
              │
   중요 기사만 │
              ▼
           Slack   ────────────기록──> Google Sheet
        개인 채널 발송                (발송 이력 자동 추가)
```

## 3. 요구사항

### REQ-01 :: 수집 (RSS)

- 서로 다른 매체의 뉴스 RSS 피드를 **최소 2개** 연결합니다.
- 피드를 2개 이상 쓰는 이유는 커버리지 때문만이 아닙니다. 
한 피드가 비거나 장애가 났을 때 브리핑이 통째로 멈추지 않게 하는 안전장치이기도 합니다.

### REQ-02 :: 트리거 (스케줄)

**매일 아침 8시 30분**에 워크플로우가 스스로 실행되어야 합니다.

- 아무것도 누르지 않아도 아침에 브리핑이 도착해야 합니다
- TIP) 검증할 때는 다음 날 아침까지 기다리지 말고, 수동으로 눌러보며 확인하세요.

### REQ-03 :: 중복 발송 방지

어제 보낸 기사가 오늘 브리핑에 다시 들어가면 안 됩니다.

- 구글 시트의 발송 이력과 대조해 이미 보낸 기사를 걸러냅니다.
- 기사를 구분하는 **고유값**을 무엇으로 삼을지 정하고, 그 근거를 제출 문서에 적습니다.
- 반드시 LLM 호출 이전에 차단합니다.

### REQ-04 :: 금융 키워드 필터

수집한 기사 중 금융 관련 기사만 남깁니다.

- 금융과 무관한 기사(연예, 스포츠, 날씨 등)가 브리핑에 들어가면 안 됩니다
- 어떤 키워드를 어떤 방식으로 적용할지는 여러분이 설계합니다.
- 필터를 **LLM 호출 앞에 둘지 뒤에 둘지**를 판단하고, 그 이유를 제출 문서에 적어주세요. 
이 선택이 비용과 정확도를 결정합니다.

### REQ-05 :: LLM 요약과 중요도 분류

걸러진 기사에 대해 아래 4개 필드를 **구조화 출력(JSON)** 으로 반환해야 합니다.

| 필드 | 타입 | 허용값 |
| --- | --- | --- |
| `summary` | string | 3문장 이하 |
| `importance` | number | 1 ~ 5 (정수) |
| `category` | string | 증시 / 금리 / 환율 / 부동산 / 기업 / 정책 / 기타 |
| `needs_review` | boolean | 검증 실패 시 true |

**중요도 판정 기준** (프롬프트에 명시할 것)

- `5` :: 시장 전체를 흔드는 사건. 금리 결정, 대형 정책 발표, 급락과 급등
- `4` :: 특정 업종이나 대형 기업에 직접 영향. 실적 발표, 대형 인수합병
- `3` :: 참고할 만한 동향. 지표 발표, 업계 전망
- `2` :: 일반적인 소식
- `1` :: 브리핑에 넣을 필요 없는 기사

**디스코드 발송 대상은 중요도 4 이상**입니다.

### REQ-06 :: 디스코드 브리핑 발송

중요 기사를 하나의 메세지로 **묶어** 개인 디스코드 채널로 발송합니다.

- 기사가 5건이면 메시지 5개가 아니라 **메시지 1개**여야 합니다
- 사람이 읽고 싶은 형태로 정리합니다. 제목, 요약, 원문 링크, 카테고리가 기사마다 들어가야 합니다
- **중요 기사가 하나도 없는 날의 경로도 설계하세요.** 아무 일도 일어나지 않는 것과 시스템이 고장 난 것을 받는 사람이 구분할 수 있어야 합니다.

**메시지 예시**

```
📈 오늘의 금융 브리핑 (2026-08-10)
읽을 기사 3건

[1] 증시 | 한국은행 기준금리 3.0% 동결
    금통위가 기준금리를 만장일치로 동결했다. 물가 안정세를
    확인했으나 가계부채 부담을 고려한 결정으로 해석된다.
    🔗 https://...

[2] 기업 | 삼성전자 2분기 영업이익 12조 원
    ...
    🔗 https://...

[3] 환율 | 원달러 환율 1,340원대 마감
    ...
    🔗 https://...
```
