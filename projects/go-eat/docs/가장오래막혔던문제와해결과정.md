# 가장 오래 막혔던 문제와 해결 과정

## 1. 어떤 상황이었나

실습을 처음 시작할 때 폴더 이름을 한글로 "맛집실습"이라고 만들고, 그 안에 Next.js 프로젝트를 만들려고 했다.

## 2. 어떤 에러/증상이 나왔나

```
Could not create a project called "맛집실습" because of npm naming restrictions:
    * name can only contain URL-friendly characters
```

폴더 이름을 영어 대문자로 바꿔봐도 또 막혔다.

```
Could not create a project called "GoEat" because of npm naming restrictions:
    * name can no longer contain capital letters
```

거기다 나중에 개발 서버를 다시 켜려고 할 때도 에러가 났다.


이것 때문에 로컬 테스트도, Vercel 배포 확인도, Supabase 연동 확인도 계속 지연됐다.


## 3. 원인이 무엇이었나

Next.js 프로젝트를 만들면 폴더 이름이 그대로 npm 패키지 이름으로 쓰이는데, npm 패키지 이름은 한글·대문자·띄어쓰기를 쓸 수 없다는 규칙이 있었다. 그래서 한글 폴더 안에서는 애초에 프로젝트 생성 자체가 안 됐던 거였다.

거기다 예전에 켜뒀던 개발 서버 프로세스가 종료되지 않고 포트를 계속 붙잡고 있어서, 새로 서버를 켜려고 할 때마다 계속 막혔다. 폴더 이름 문제와 포트 점유 문제가 겹치면서 배포·DB 확인 작업이 한참 지연됐다.

## 4. 어떻게 해결했나

AI에게 에러 메시지를 그대로 보여주면서 "왜 이런 에러가 나는지, 어떻게 해야 하는지" 물어봤다. 폴더 이름을 영어 소문자로 바꿔야 한다는 걸 알게 됐고, 임시 폴더에 영어 소문자 이름(`go_eat`)으로 프로젝트를 새로 만든 다음 파일만 원래 위치로 옮기는 방식으로 해결했다.

포트가 안 풀리는 문제는 어떤 프로세스가 그 포트를 쓰고 있는지 확인해달라고 했고, 확인된 프로세스를 강제로 종료한 뒤에야 새 서버가 정상적으로 켜졌다.
