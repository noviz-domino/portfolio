# 회고 — 가봐야 알지 (GoEat)

## 배포 링크

https://go-eat-noviz.vercel.app

테스트 계정: `test1@goeat.test` / `test1234`

## 만든 것

가고 싶은 맛집을 저장하고, 다녀온 곳에 별점을 남기는 맛집 관리 서비스.
등록, 조회, 수정, 삭제 다 되고 검색이랑 필터도 붙였다.

## 겪은 것들


배포 주소가 처음에 이상한 글자가 붙어서 나왔다go-eat-xi.vercel.app. 
go-eat이라는 이름을 이미 딴 사람이 쓰고 있어서 그런 거였다. 그래서 새로 이름을 정해서 등록했다.

디자인 색깔 고를 때는 그냥 색 코드만 던져주는 대신, 실제 버튼·탭 모양에 색 세 개를 입혀서 비교하는 화면을 만들어줘서 그거 보고 하나 골랐다. 말로만 듣는 것보다 훨씬 고르기 편했다.


## 느낀 점

기획을 먼저 자세히 해두니까 나중에 화면 만들 때 고민할 게 별로 없었다. 등록/상세/수정/삭제 다 만들고 실제 배포 사이트에서 되는 거 봤을 때 제일 뿌듯했다.
