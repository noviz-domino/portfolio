# 1단계: 코어 루프

## 목표 (기획서 §14-1)
이동 / 자동조준 / 기본무기 1종 / 충돌 / HP / 게임오버 뼈대 확인

## 구현 내용
- `index.html` 단일 파일 구조 착수. 섹션 배너 주석으로 §12 기술 아키텍처의 모듈 분리 반영
  (CONFIG / 유틸 / 오브젝트 풀 / 엔티티 / 시스템 / 상태머신 / UI 브릿지 / 렌더러 / 메인 루프 / 부트스트랩)
- **이동**: WASD/방향키 8방향, 가속 3000px/s²·감속 3600px/s², 최고속 260px/s, 대각 정규화, 아레나(2400×1600) 경계 클램프
- **자동조준 사격**: 펄스 캐논(AIMED) — 최근접 적 탐색 후 조준 발사, 쿨다운 0.45s
- **대시**: Space 탭 → 이동 방향(facing)으로 180px 대시, 0.20s 무적, 3s 쿨다운. 플레이어를 감싸는 대시 쿨다운 원호 HUD 구현(§11)
- **충돌**: 전부 원-원 판정(제곱거리, sqrt 없음). 적 판정 +2px 보너스(§4 히트박스 원칙), 플레이어 판정은 코어 반경 4px 그대로
- **HP**: 코어 무결성 5칸, 피격 시 1칸 감소 + 무적 1.1s + 히트스톱 0.12s + 넉백(샌드위치 데스 방지)
- **오브젝트 풀**: 적탄/적 배열 기반 free-index 스택 풀링 (§12 구조 선반영, 스테이지1은 적 260 슬롯만 사용)
- **상태머신**: MENU → PLAYING → RESULT. `safeTransition()` 재진입 가드 적용, 리스너는 부트스트랩 시 단 1회 등록 (R5 사전 반영)
- **테스트용 스폰**: 잡몹 드리프터(직선추격) 1.2초 간격 스폰, 스폰 안전반경 260px 적용
- **결과 화면**: SCORE 공식(§8 R2) 중 생존시간·킬수 기반 부분 반영, FAILED/CLEAR 통일 로직(`finalizeRun`)

## 브라우저 검증 결과
- 메인 메뉴 조작법 카드 노출 확인
- 출격 → 플레이어 삼각형 렌더링(청록 글로우) + 대시 쿨다운 원호 정상 표시
- 적(보라 삼각형) 스폰 → 자동조준탄(앰버, 색상 계약 준수)이 최근접 적을 추적/처치 → KILL/SCORE 실시간 갱신 확인
- 강제 데미지 호출로 코어 무결성 0 도달 시 FAILED 결과 화면 및 SCORE 브레이크다운(생존시간/킬수) 정상 출력
- `다시 출격` 클릭 → 타이머/HP/킬수 완전 초기화 후 즉시 재진입 확인(로딩 없음)
