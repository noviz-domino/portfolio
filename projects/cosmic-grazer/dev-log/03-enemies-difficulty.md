# 3단계: 잡몹/원거리 적 + 난이도 스케일링 + 공정성 규칙 + 탄 캡 정책

## 목표 (기획서 §14-3)
잡몹4 + 원거리4 스폰/AI + 시간기반 난이도 스케일링 + 공정성 규칙(색상계약/텔레그래프/스폰안전반경) + 탄 캡 삭제 정책(§13-2)

## 구현 내용

### 적 8종 데이터 테이블 (§6)
- **잡몹 4종**: 드리프터(직선추격, 삼각) / 슬라이서(정지조준→돌진, 사각 — `idle→telegraph(0.5s)→dash(고속돌진)→cooldown` 상태머신) / 스포어 클러스터(삼각, 사망 시 2체 분열 — `isSplitChild` 플래그로 재분열 방지) / 크리퍼(삼각, 초고속저체력)
- **원거리 4종**: 터렛 크랩(육각, 3-way 부채꼴) / 사이퍼(육각, 8방향 원형산탄) / 스나이퍼 아이(육각, 조준선 예고 0.5s + 고속(620px/s) 단발 — 탄속 300↑ 텔레그래프 의무 규칙 준수) / 위버(육각, 사인파 이동 + 회전 나선탄)
- 색상 규약(§6) 그대로 반영: 잡몹 저채도 보라, 원거리 고채도 마젠타(`#ff4dd8`). 도형 규약(삼각=돌진/사각=근접추격/육각=원거리)도 반영

### AI 시스템
- `AI.behaviors`에 `chase/dash/split/fan/radial/snipe/sine` 7개 행동 함수, 원거리 적 공통 로직은 `keepDistance()`(선호 사거리 유지) + `tickRangedAttack()`(쿨다운→텔레그래프→발사)로 재사용
- **적 개체 상호반발**(§7 공정성 요구사항): 그리드 기반 3×3 인접 조회로 겹친 개체를 밀어내 뭉침 방지

### 시간 기반 난이도 스케일링 (§7)
- `CONFIG.DIFFICULTY`: 적HP배율 `1+0.32t+0.028t²`, 스폰율 `1.4+0.85t`/초, 동시적 상한 `min(55+17t,300)`, 동시탄 상한 `min(120+62t,900)`, **탄속 배율 상한 1.5**로 강하게 제한 — 모두 문서 수식 그대로 구현
- 스폰 시 원거리 비중이 시간 경과에 따라 15%→55%로 점증(초반은 잡몹 위주)

### 공정성 하드 요구사항 반영
- 스폰 안전반경 260px(적) 유지, 적탄은 항상 원거리 적의 `keepDistance` 로직으로 근접 난사 방지
- 텔레그래프 의무화: 모든 원거리 공격에 0.35~0.5초 예고(마젠타 조준선 렌더링), 슬라이서 돌진도 0.5초 예고(적 주위 링)
- 색상 계약: 적탄 = 마젠타 + 흰 코어, 아군탄 = 앰버(기존), 적탄은 렌더 파이프라인 최상위(플레이어보다 나중에 그림)
- 60fps 방어를 위한 오브젝트 풀: 적탄 풀 950(§12 규모 반영), free-index 스택

### 탄 총량 하드캡 삭제 정책 (§13-2)
- 판정 기준을 아레나 경계가 아닌 **카메라 뷰포트 + 패딩 300px 밖**으로 구현
- 모든 적탄에 `priority` 필드(현재는 전부 1, 보스/엘리트 도입 시 2로 태깅 예정 — §14 4단계)
- 하드캡(900) 초과 시 1차: 뷰포트+패딩 밖 && priority<2 우선 제거 → 2차: priority<2 전체 대상 추가 제거

## 브라우저 검증 결과
- 콘솔 에러 없음
- 적 8종 모두 스폰 확인: 삼각(잡몹)/사각(슬라이서, HP바 노출)/육각(원거리, HP바 노출) 형태 구분 렌더링
- 마젠타 조준선 텔레그래프 및 적탄(마젠타+흰 코어) 렌더링 색상 계약 확인
- 게임오버(FAILED, 생존 33.4s/레벨3/킬46/점수564) → 재출격 → 즉시 재개 흐름 정상
- 43초 시점 풀 카운트 점검: 적탄 107개(캡 900 이내), 적 47개(캡 이내), 파편 8개 — 누수 없이 안정적
