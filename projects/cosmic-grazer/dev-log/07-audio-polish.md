# 7단계: 절차적 SFX + 폴리싱 (최종 단계)

## 목표 (기획서 §14-7)
절차적 SFX(디바운스 게이트 포함, §13-3) + 폴리싱(글로우 스프라이트 캐싱, 화면흔들림, 텔레그래프 연출)

## 구현 내용

### 절차적 오디오 (§13-3)
- `AudioSystem`: WebAudio `OscillatorNode` + `GainNode` 기반 순수 절차적 SFX, 외부 파일/BGM 전혀 없음
- 이벤트별 파형/주파수/슬라이드로 구분: 타격(사각파 하강)/처치(톱니파 하강)/피격(사각파 저음)/그레이즈(사인파 상승)/대시(삼각파 상승)/파밍(사인파 상승)/레벨업·보스등장·오버드라이브·클리어(드문 이벤트, 게이트 없음)
- **디바운스 게이트**(§13-3 명시값 그대로): 타격 45ms / 처치 30ms / 피격 80ms / 그레이즈 60ms / 대시 100ms / 파밍 35ms — `performance.now()` 기준 이벤트별 마지막 재생 시각 기록, 미달 시 재생 스킵
- `AudioContext`는 지연 생성(`ensureCtx()`) — 브라우저 자동재생 정책 대응, 사용자 첫 상호작용(버튼 클릭 등) 시점에 생성/resume
- 발생 지점 연결: 피격(타격음), 처치(킬음), 피격당함(허트음+화면흔들림), 그레이즈(양쪽 판정 모두), 대시, 파편 획득, 레벨업 드래프트 시작, 보스 스폰, 오버드라이브 발동, 런 종료(클리어/실패)

### 글로우 스프라이트 캐싱 (§7 60fps 방어)
- `GlowSpriteCache`: 색상+반경 조합별로 방사형 그라디언트 글로우를 오프스크린 캔버스에 1회만 렌더링 후 `Map`에 캐시
- 아군탄(앰버)·적탄(마젠타) 렌더링에서 매 프레임 `ctx.shadowBlur` 연산 대신 캐시된 스프라이트를 `drawImage`로 재사용 — 탄이 수백 개로 늘어나는 후반 웨이브에서 그림자 연산 비용 절감

### 화면 흔들림
- `Camera.shake(mag, duration)` — 피격 시(강도6), 보스 스폰 시(강도14), 오버드라이브 발동 시(강도10) 트리거
- `Camera.update()`에서 남은 시간에 비례해 감쇠하는 랜덤 오프셋을 카메라 좌표에 더해 자연스러운 감쇠 효과

### 텔레그래프 연출 강화
- 스폰 텔레그래프(주황 링): `performance.now()` 기반 사인파로 반경·투명도가 맥동해 시선을 끄는 경고 강조
- 원거리 적 공격 조준선(마젠타): 발사 임박할수록(`atkTelegraph` 잔여시간 감소에 비례) 선이 더 밝고 두꺼워져 발사 타이밍을 예측하기 쉽게 개선

### 디버그 오버레이 (§15 검증 도구)
- 백틱(`) 키로 토글, FPS(최근 30프레임 평균)·활성 적/적탄/아군탄/파편 개수를 실시간 표시
- 후반 웨이브에서 60fps 유지 여부를 직접 확인할 수 있는 §15 요구사항 반영

## 브라우저 검증 결과
- 콘솔 에러 없음
- `AudioSystem.ctx` 생성 및 `state: 'running'` 확인(사용자 클릭 이후)
- 디바운스 게이트 단위 테스트: 동일 이벤트 연속 호출 시 첫 호출만 통과, 즉시 재호출은 차단됨을 확인
- `Game.damagePlayer()` 호출 시 `Camera.shakeTimer/shakeMag`가 즉시 설정됨을 확인
- 글로우 스프라이트 적용 후 화면 스크린샷에서 탄environment 주변 부드러운 발광 확인(시각적 회귀 없음)
- 디버그 오버레이 활성화 후 실제 전투 중(적20/적탄91/아군탄12/파편31 동시 존재) **FPS 60 유지** 확인

## 참고
- 자동화 테스트 환경에서 백틱 키의 `computer.key` 시뮬레이션이 `Backquote` 코드로 정확히 매핑되지 않는 경우가 관찰되어 `DebugOverlay.toggle()`을 직접 호출해 검증함 — 실제 물리 키보드 환경에서는 `Backquote` 코드가 정상적으로 발생하므로 실사용에는 영향 없음
- §14 7단계 우선순위를 마지막으로 계획된 전체 개발 단계가 완료되었습니다. 각 단계 dev-log에 기록된 후속 검증 권장 사항(미러 워든 정밀 타이밍, 세라프-01 실제 히트스캔 레이저 시각화, 심연모드 장시간 티어 증가)은 실제 플레이테스트에서 추가 확인이 필요합니다.
