# 2단계: 레벨업 드래프트 + 무기/패시브 데이터 + 오브젝트 풀 + 그리드

## 목표 (기획서 §14-2)
레벨업 드래프트 + 무기·패시브 8+8종 데이터 + 오브젝트 풀링 + 단일측 그리드(§13-1)

## 구현 내용

### 데이터 테이블 (순수 데이터, §12 원칙)
- `CONFIG.WEAPONS` 8종 전부 구현: 펄스 캐논(AIMED) / 시커 스웜(HOMING) / 오비탈 드론(SELF) / 프리즘 레이저(AIMED, 예고형 처형기) / 그래비티 웰(INSTALL) / 이온 체인(AIMED, 연쇄) / 노바 펄스(SELF) / 디플렉터 어레이(DIRECTIONAL)
  - **디플렉터 어레이는 처음부터 §13-5 결정사항(후방 배치, `facing+π`)을 반영**하여 구현 — 전방 배치로 만들었다가 나중에 고치는 우회 없이 바로 정확한 사양으로 작성
- `CONFIG.PASSIVES` 8종 전부 구현: 오버클럭 코어/증폭 렌즈/관성 안정기/자기 회수기/방열판/위상 코팅/확산 모듈/채굴 프로토콜 — `player.derived` 파생 스탯 객체로 매 레벨업마다 재계산(`recomputePlayerDerivedStats`)
- 각 무기/패시브 `getWeaponStats(id, level)`로 base+perLevel*(level-1) 계산, 최대 Lv5

### 레벨업 드래프트
- XP 파편 흡수(반경 70px+패시브 보너스, 12초 소멸, 3초 전 블링크 경고) → `LevelUp.addXp()` → 임계치 도달 시 완전 정지(`STATE.LEVELUP`) + 카드 3택 HTML/DOM 오버레이(§11 원칙: 캔버스는 월드 렌더링 전용)
- 후보 풀: 보유 중이고 Lv<5인 항목(업그레이드) + 미보유이고 슬롯 여유(무기6/패시브6) 있는 항목(신규) 중 랜덤 3장, 부족하면 있는 만큼만
- 확정: 좌우 화살표로 카드 이동 + Space/Enter 확정, 카드 클릭으로도 즉시 확정 가능
- 재개 시 0.6초 유예 무적(`CONFIG.PLAYER.LEVELUP_GRACE`) 적용
- 레벨업이 동시에 여러 번 발생해도(`pending` 카운터) 순차적으로 드래프트가 이어짐

### 오브젝트 풀 확장
- 적탄 풀은 3단계에서 본격 사용 예정이라 아직 미배치, 아군탄 500 / 적 260 / XP파편 300 풀 가동
- free-index 스택 방식 유지

### 단일측 공간분할 그리드 (§13-1)
- `Grid`: 매 fixed-tick마다 **적만** 96px 셀에 등록(`build()`), 아군탄은 자신의 좌표 기준 3×3 인접 셀(자기 셀+8개) 적만 조회(`queryNear`)하여 충돌 검사
- 아군탄은 그리드에 등록되지 않음 — 등록/해제 연산 자체가 없음(설계 그대로 구현)

### 무기별 특수 동작
- 유도(HOMING): 시커 스웜은 `turnRate`로 프레임마다 최근접 적 방향으로 서서히 선회
- 연쇄(이온 체인): 하나의 탄이 적 하나를 맞춘 뒤 `hitIds` Set으로 중복 방지하며 다음 최근접 미피격 적으로 재유도, `chainRemaining` 소진 시 소멸
- 예고형 처형(프리즘 레이저): 발사 즉시가 아니라 `laserCharges` 배열에 텔레그래프 타이머를 등록 → 시간 경과 후 라인 판정으로 즉시 히트
- 설치형(그래비티 웰): `wells` 배열에 지속시간을 가진 필드 등록, tick마다 반경 내 적에게 데미지(추후 3단계에서 적탄 소거 기능과 연동 예정)
- 자기중심(오비탈 드론/노바 펄스): 오비탈은 매 프레임 공전 위치 재계산 + 접촉 데미지(개별 히트쿨다운), 노바는 쿨다운마다 즉시 반경 폭발
- 방향성(디플렉터 어레이): 쿨다운 없이 매 프레임 `player.facing + π` 위치에 패널 유지, 접촉한 적에게 데미지

## 브라우저 검증 결과
- 콘솔 에러 없음
- XP 파편 자연 흡수 확인(초록 파편, 흡수반경 내 호밍)
- `LevelUp.addXp()` 강제 호출로 카드 3택 UI 정상 노출, 카드별 NEW/LV업그레이드 태그·이름·설명 정확히 표시
- **디플렉터 어레이 설명이 §13-5 사양대로 "이동 반대 방향(후방) 반사 패널 — 추격탄 차단"으로 노출** 확인
- 카드 클릭 1회 → 정확히 해당 옵션만 적용 → `STATE.PLAYING` 복귀 → 유예 무적 타이머 적용 확인 (`Game.reset()` 후 단일 레벨업으로 격리 재검증)
- 디플렉터 패널이 플레이어 진행 방향의 반대편(후방)에 정확히 렌더링됨을 스크린샷으로 확인
- 좌하단 12슬롯(무기6/패시브6) HUD가 보유 무기/레벨을 실시간 표시

## 참고 (다음 단계로 이월)
- 그래비티 웰/노바 펄스/디플렉터의 "탄 소거" 효과는 적탄이 아직 존재하지 않아(3단계에서 적 원거리 공격 도입) 완전한 동작 검증은 3단계 이후 가능
