# 5단계: 진화 4종 + 그레이즈/오버드라이브

## 목표 (기획서 §14-5)
진화 4종 + 그레이즈/오버드라이브(파편 회수 보너스, §13-4) — 디플렉터 후방 재정의(§13-5)는 2단계에서 이미 반영 완료

## 구현 내용

### 진화 4종 (§5)
- `CONFIG.EVOLUTIONS`: 무기 Lv5 + 지정 패시브 Lv3 이상 조건 정의
  - 펄스 캐논 + 증폭 렌즈(Lv3) → **트윈 랜스**(2갈래 관통탄, `pierce` 플래그로 동일 적 재타격 없이 직진 관통)
  - 오비탈 드론 + 확산 모듈(Lv3) → **새턴 링**(드론 수/반경 확장)
  - 그래비티 웰 + 위상 코팅(Lv3) → **싱귤래리티**(지속 흡인력 `pullForce` + 광역 붕괴장)
  - 디플렉터 어레이 + 관성 안정기(Lv3) → **미러 볼트**(패널에 닿는 적탄 소거 + 최근접 적에게 반격탄 발사)
- `LevelUp.getEligibleEvolutions()`가 조건 충족 시 진화 카드를 **최우선으로 드래프트에 삽입**(황금 테두리 CSS `.card.evolution`), 나머지 2장은 일반 후보로 채움
- 확정 시 기존 기본 무기 슬롯을 제거하고 진화 무기를 레벨1로 새로 장착 (`applyOption` kind:`evolution` 분기)
- 무기 시스템을 `family`(orbital/deflector) 기반으로 일반화하여 오비탈 드론↔새턴 링, 디플렉터 어레이↔미러 볼트가 동일한 `OrbitalSystem`/`DeflectorSystem`을 공유하도록 리팩터링

### 그레이즈 (§4)
- `GrazeSystem`: 매 tick 활성 적탄 중 아직 그레이즈 안 된(`_grazed=false`) 탄에 대해 코어(r4)~그레이즈 링(r22) 사이 거리 판정, 1회만 카운트(재판정 방지)
- 대시 무적 중 코어 반경 이내로 적탄이 겹치면(관통) 추가 오버드라이브 게이지 보너스(`DASH_PIERCE_GAIN`) — §4 "탄 관통 시 게이지 충전" 반영
- 그레이즈 획득량은 위상 코팅 패시브의 `grazeGainMult`로 스케일링

### 오버드라이브 (§4, §13-4)
- Space 홀드 0.35초 + 게이지 100% 충족 시 `Game.activateOverdrive()` 발동:
  1. 화면의 모든 적탄 전멸(`enemyBulletPool` 전체 반환)
  2. **필드에 남은 모든 XP/에센스 파편 즉시 전량 회수**(파편별 `LevelUp.addXp` 호출 후 반환) — 그레이즈로 채운 게이지가 "탄막을 뚫고 쓸어담기"로 직결되는 §13-4 리스크/리워드 연결 구현
  3. 데미지 50% 증가 5초 (`getEffectiveDamageMult()` 헬퍼로 전 무기 데미지 계산에 일괄 적용)
  4. 무적 1초
  5. 게이지 0으로 초기화
- HUD에 오버드라이브 게이지 바 추가(좌상단 코어 무결성 칸 아래, §11), 게이지 100% 도달 시 흰색 발광으로 강조
- 오버드라이브 활성 중 플레이어 기체 색상/글로우가 금색으로 변화(시각 피드백)
- 플레이어 주변 그레이즈 링(r22) 얇은 참고선 렌더링 추가

## 브라우저 검증 결과
- 콘솔 에러 없음
- 진화 조건 격리 테스트: `pulse_cannon Lv5 + amplifier_lens Lv3` → `getEligibleEvolutions()`가 `twin_lance` 카드 정확히 반환, 드래프트 옵션에 진화 카드가 최우선 포함됨을 확인
- `gravity_well Lv5 + phase_coating Lv3` → `singularity` 진화도 동일하게 확인, 확정 후 무기 슬롯이 `gravity_well` 제거+`singularity` Lv1 추가로 정확히 치환됨을 확인
- 그레이즈 격리 테스트: 코어~그레이즈 링 사이(거리15, 링범위 7~25)에 배치한 적탄 1개로 게이지 정확히 `+7`, `grazeCount` 1 증가, 동일 탄 재카운트 없음 확인
- 오버드라이브 격리 테스트: 게이지 100% 도달 후 발동 → 적탄 55→0, 파편 14→0 전량 회수, `overdriveTimer=5`, `invulnTimer=1`, `getEffectiveDamageMult()=1.5` 즉시 확인 후 5초 경과 시 자동으로 1.0 복귀 확인

## 참고
- 진화/레벨업 드래프트 자체의 좌우 화살표+Space 확정 로직은 2단계에서 이미 검증되어 재검증 생략(§13-5 디플렉터 후방 재정의도 2단계에서 최초 구현 시점부터 반영되어 이번 단계에서 추가 변경 없음)
- Space "홀드 vs 탭" 판정은 단순화하여 구현: 탭 시 즉시 대시가 발동하고, 그 상태로 0.35초 이상 계속 누르고 있으면(게이지 100% 조건 충족 시) 추가로 오버드라이브가 함께 발동하는 레이어드 방식. 대시와 오버드라이브가 상호 배타적인 "택일형 홀드 판정"은 아님 — 실제 플레이 감각은 7단계 폴리싱에서 재검토 권장
