# 4단계: 엘리트 3종 + 보스 3종 패턴

## 목표 (기획서 §14-4)
엘리트3 + 보스3 패턴 구현 (priority=2 태깅 포함)

## 구현 내용

### 엘리트 3종 (§6)
- **오벨리스크**: 고정형(speed 0), 0.15초마다 `spiralStep(-0.28)`씩 각도를 누적하며 역회전 나선탄 발사. **의도된 탄막 패턴이므로 §13-2 정책대로 `priority=2`로 태깅**
- **캐리어**: 플레이어에게 서서히 접근하며 `summonInterval`(4초)마다 드리프터 1체를 근처에 소환(`Spawner.spawnEnemy` 재사용)
- **미러 워든**: 항상 플레이어 쪽으로 서서히 회전하는 `facingAngle`(턴레이트 1.5rad/s로 제한) 보유. 충돌 처리 시 `facingAngle` 기준 전방 반호(§`MIRROR_FRONT_HALF_ARC`=0.55π) 안에서 맞으면 데미지 무효(방어막 흡수), 후방에서 맞으면 정상 데미지 — "위치선정 강제" 기믹을 턴레이트 지연으로 구현(플레이어가 회전 속도보다 빠르게 측후방으로 돌아가야 유효타)

### 보스 3종 (§6)
- **세라프-01**(4:00 트리거, HP3500): `spiral`(4s, 회전 나선탄) → `burst`(2.4s, 조준탄 5연발) → `sweep`(3s, 조준 기준 180° 부채꼴을 촘촘한 연사로 스캔 — 실제 히트스캔 레이저 대신 다수의 개별탄으로 스윕을 근사 구현, 정밀 레이저 시각화는 7단계 폴리싱 후보) 순환
- **하이브-퀸 크로노스**(8:00, HP14000): `gate`(4s, 플레이어 수직 방향으로 벽 형태 탄막 + 랜덤 갭 1칸) ↔ `ring`(4s, 반경 260 링을 안쪽으로 수축시키는 탄막) 교대
- **특이점 코어**(12:00, HP45000): 3페이즈 순환 — `drift`(플레이어에 약한 중력 견인력 적용 + 저속탄) → `collapse`(반경 320 링이 중심으로 붕괴하는 격자형 탄막) → `safezone`(회전하는 좁은 갭을 제외한 전방위 탄막)
- 보스 사망 판정: `특이점 코어` 격파 시 `Game.finalizeRun('CLEAR')` 연결(§10 승리 조건의 최소 배선 — 탈출/심연 선택 UI는 6단계에서 완성)
- 모든 보스 탄에 `priority=2` 태깅(§13-2 하드캡 삭제 정책에서 보호 대상)
- 보스 등장 시 하단 전용 HP바 + 이름(HTML/DOM, §11) 노출, 스폰 시 1.2초 텔레그래프

### 데이터/시스템
- `BossManager`: `Game.time` 기준 트리거(240/480/720s)로 1회씩 자동 스폰, `Game.reset()`에 상태 초기화 연동
- `Spawner`에 엘리트 스폰 로직 추가(2:00 이후, 동시 최대 3체, 28~38초 간격)
- 보스/복합 도형 렌더링: 16각 별 형태 + 붉은 림라이트(백색+림라이트 색상 규약 §6 준수)

## 브라우저 검증 결과
- 콘솔 에러 없음
- `Game.time`을 240s 부근으로 강제 이동시켜 세라프-01 정상 스폰(HP3500) 및 하단 HP바("세라프-01") 노출 확인
- 우선순위 태깅 확인: 활성 적탄 중 `priority=2`(보스 탄막) 다수 확인, 보스 페이즈가 `spiral→burst`로 전환되는 것도 상태값으로 확인
- 오벨리스크 격리 스폰 후 2초간 `priority=2` 탄 36개 발사 확인(연속 나선탄 정상)
- 캐리어 격리 스폰 후 드리프터 자동 소환 확인(총 개체 수 증가, DRIFTER 타입 포함)
- 미러 워든: `facingAngle`이 플레이어 방향으로 제한된 회전속도(1.5rad/s)로 서서히 수렴하는 것을 반복 측정으로 확인, 전방 정렬 상태에서의 피격은 데미지 무효 처리됨을 확인. **다만 "회전 지연을 이용한 후방 기습" 타이밍 창 자체는 자동화 스크립트의 왕복 지연 때문에 정밀 재현이 어려워, 이 부분은 실제 플레이 감각 검증이 필요 — 7단계(폴리싱) 또는 수동 플레이테스트에서 재확인 권장**

## 참고 (다음 단계로 이월)
- 세라프-01의 "레이저 스윕"은 연사 근사 구현 — 실제 히트스캔 라인 렌더링(시각적 사실감)은 7단계 폴리싱 후보
- 보스 격파 후 "탈출/심연으로" 선택 UI, 승리 조건 전체 플로우(§10)는 6단계(메타 진행 + 결과화면 + 심연모드)에서 완성
