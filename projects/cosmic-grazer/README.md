# 스쳐야 산다 (COSMIC GRAZER)

우주를 배경으로 한 로그라이크 탄막 서바이버 게임입니다. 순수 Vanilla JS + Canvas2D로 만든 **단일 `index.html` 파일**로 동작하며, 외부 라이브러리·CDN·서버 없이 브라우저 하나로 바로 플레이할 수 있습니다.

▶ **온라인으로 바로 플레이**: https://noviz-domino.github.io/cosmic-grazer/

## 게임 소개

적의 탄막 사이를 파고들며 싸우는 웨이브 서바이벌 게임입니다. 핵심은 **그레이즈(Graze)** — 적 탄을 정면으로 맞으면 죽지만, 코어 바로 바깥의 좁은 링을 아슬아슬하게 스쳐 지나가면 오버드라이브 게이지가 채워집니다. 게이지가 가득 차면 화면의 적탄을 전멸시키고 데미지를 대폭 올려주는 오버드라이브를 발동할 수 있습니다 — 안전하게 도망만 다니면 강해질 수 없는, "피하는 재미"와 "쌓는 재미"가 함께 가는 구조입니다.

### 핵심 기능
- **무기 8종 + 진화 4종**, **패시브 8종** — 레벨업마다 카드 3장 중 선택해 빌드를 구성
- **잡몹 4종 + 원거리 4종 + 엘리트 3종 + 보스 3종** — 시간이 지날수록 강해지는 난이도 스케일링
- **보스전**: 등장 시 경고 배너·화면 플래시·강한 카메라 흔들림과 함께 다른 적이 모두 사라지고 보스와의 1:1 전투로 전환, 배경음악도 더 긴박하게 전환
- **그레이즈 / 오버드라이브** 리스크·리워드 시스템
- **격납고**: 코어 에센스(✧)로 구매하는 영구 강화 트리 (HULL / ARMS / SYS 3계통)
- **명예의 전당**: 조종사 이름별로 전체 누적 점수를 기록하는 로컬 랭킹 (상위 5)
- **심연 모드**: 최종 보스 격파 후 선택 가능한 엔들리스 모드
- 절차적 WebAudio 사운드 & 배경음악 (외부 오디오 파일 전혀 없음)

### 조작법
| 키 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| `Space` 탭 | 위상 이탈 (대시) |
| `Space` 홀드 (게이지 만충 시) | 오버드라이브 발동 |
| 자동 조준 사격 | 최근접 적을 자동으로 공격 |
| `←` / `→`, `Space`/`Enter` | 레벨업 카드 선택 |

## 로컬에서 실행하기

설치나 빌드 과정 없이 `index.html`을 더블클릭해서 브라우저로 열면 바로 실행됩니다.

```bash
git clone https://github.com/noviz-domino/cosmic-grazer.git
cd cosmic-grazer
# index.html을 브라우저로 열기
```

## 기술 스택

- Vanilla JavaScript + Canvas2D (프레임워크 없음)
- WebAudio API (절차적 SFX + 배경음악)
- `localStorage` 기반 세이브(격납고 진행상황, 명예의 전당)
- 단일 HTML 파일 — 빌드 도구 없음
