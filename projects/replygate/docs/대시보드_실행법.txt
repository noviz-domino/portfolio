ReplyGate 대시보드 실행법 (Git Bash 기준)
==========================================

[준비]
Git Bash 열기 → 아래 경로로 이동
cd /c/Users/HOME/Desktop/replygate


[방법 1] 데모 모드 - 가짜 데이터, 시트 연결 없음 (화면만 확인할 때)
------------------------------------------------------------
REPLYGATE_DEMO=1 python dashboard/app.py

브라우저에서 http://127.0.0.1:8000 접속


[방법 2] 실제 모드 - 실제 시트 + 텔레그램 연동 확인 (리허설용, 권장)
------------------------------------------------------------
REPLYGATE_SHEET_ID="1j3_T7KfrUBZr9wqSiKjEXDN8LBr1D2GaMwy4909eObI" REPLYGATE_SA_KEY="dashboard/keys/sa-key.json" python dashboard/app.py

브라우저에서 http://127.0.0.1:8000 접속


[끄는 법]
------------------------------------------------------------
방법 A: 실행 중인 터미널 창에서
Ctrl + C

방법 B: 터미널을 닫아버렸을 때 (새 Git Bash 창에서)
1) 포트 사용 중인 프로세스 확인
   netstat -ano | grep :8000

2) 맨 오른쪽 숫자(PID)를 확인 후 종료
   taskkill //F //PID <확인한_숫자>

   ※ Git Bash에서는 슬래시(/) 두 개로 씀: //F //PID


[참고]
- 데모 모드는 화면 확인용, 실제 파이프라인 흐름(폼 제출 → 카드 도착)은 안 보임
- 리허설 시엔 방법 2(실제 모드)로 실행할 것
- 서비스 계정 키 경로: dashboard/keys/sa-key.json (이미 준비됨)
