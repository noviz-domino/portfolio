# 대시보드 · 실시간 상황판

구글 시트를 **읽기만** 하는 FastAPI 서버와 정적 프런트.

```
문의 시트  ──읽기──▶  FastAPI  ──SSE──▶  브라우저
```

**n8n 과 직접 통신하지 않는다.** 시트를 공용 저장소로 두고 양쪽이 각각 읽고 쓴다.
덕분에 ngrok 같은 공개 URL이 필요 없고, 이 서버가 죽어도 파이프라인은 그대로 돈다.

---

## 화면 구성

| 영역 | 내용 | 출처 |
|---|---|---|
| **실시간 상황판** | `접수됨 → 분석중 → 승인대기 → 수정중 → 발송완료` 컬럼으로 카드가 흐른다 | `문의` 시트 (실시간) |
| **운영 지표** | 1차 승인률, 평균 처리 시간, 평균 수정 횟수, 유형·분류축 분포, 인용 조항 빈도 | `문의` 시트 (실시간) |
| **실험 결과** | 평가셋 50건의 RAG vs 베이스라인 1차 승인률과 수치 오류 | `eval/측정_검수표.tsv` (정적) |

카드 배지는 텔레그램 카드와 **같은 기호**를 쓴다 — 🔴 불만 / ⚪ 일반 / 📋 주문 조회 필요 / ⚠️ 정책 미커버.
두 화면의 표기가 다르면 담당자가 헷갈린다.

> **승인 버튼은 일부러 없다.** 승인 창구를 텔레그램 하나로 유지해야 "휴대폰만으로 완결된다"는
> 설계 의도가 유지된다. 이 화면은 보기만 하는 곳이다.

## 데모 모드 — 준비 없이 바로 보기

서비스 계정도 네트워크도 필요 없다. 발표 동선 리허설과 화면 확인용이다.

```bash
REPLYGATE_DEMO=1 python dashboard/app.py
```

PowerShell 이라면:

```powershell
$env:REPLYGATE_DEMO="1"; python dashboard/app.py
```

→ <http://127.0.0.1:8000>

가짜 문의 12건이 모든 상태·배지 조합으로 깔린다. **실험 결과 패널은 데모 모드에서도 실제 측정값**을 보여준다(`eval/측정_검수표.tsv` 를 그대로 읽는다).

## 실제 시트에 연결하기

### 1. 서비스 계정 만들기

시트에 고객 이메일이 들어 있어 **웹에 게시(CSV)** 대신 서비스 계정을 쓴다. 시트를 비공개로 유지할 수 있다.

1. <https://console.cloud.google.com> → 프로젝트 선택(또는 새로 만들기)
2. **API 및 서비스 → 라이브러리** → `Google Sheets API` 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보** → **사용자 인증 정보 만들기 → 서비스 계정**
   - 이름은 아무거나 (예: `replygate-dashboard`)
   - 역할은 **지정하지 않아도 된다.** 시트 권한은 다음 단계에서 공유로 준다
4. 만들어진 서비스 계정 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 내려받기
5. 받은 JSON 안의 `client_email` 값을 복사한다 (`...@....iam.gserviceaccount.com` 형태)

### 2. 시트 공유

스프레드시트 → **공유** → 위에서 복사한 `client_email` 붙여넣기 → 권한 **뷰어** → 전송.

> 뷰어면 충분하다. 이 서버는 쓰기를 하지 않는다.

### 3. 키 파일 두기

`dashboard/` 아래에 두면 `.gitignore` 가 자동으로 걸러낸다.

```
dashboard/keys/sa-key.json
```

**커밋되지 않는지 반드시 확인할 것:**

```bash
git status --short
git check-ignore -v dashboard/keys/sa-key.json
```

### 4. 실행

```bash
export REPLYGATE_SHEET_ID="<스프레드시트 ID>"
export REPLYGATE_SA_KEY="dashboard/keys/sa-key.json"
python dashboard/app.py
```

PowerShell:

```powershell
$env:REPLYGATE_SHEET_ID="<스프레드시트 ID>"; $env:REPLYGATE_SA_KEY="dashboard/keys/sa-key.json"; python dashboard/app.py
```

스프레드시트 ID는 URL의 `/d/` 와 `/edit` 사이 문자열이다.

## 환경변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `REPLYGATE_SHEET_ID` | (필수) | 스프레드시트 ID |
| `REPLYGATE_SA_KEY` | (필수) | 서비스 계정 JSON 키 경로 |
| `REPLYGATE_DEMO` | — | `1` 이면 가짜 데이터로 실행. 위 둘이 필요 없다 |
| `REPLYGATE_PORT` | `8000` | 포트 |
| `REPLYGATE_POLL_SECONDS` | `2` | 시트를 다시 읽는 주기 |
| `REPLYGATE_PUSH_SECONDS` | `1` | 브라우저로 변경분을 밀어주는 주기 |

|---|---|
| `GET /` | 대시보드 화면 |

## 발표 당일 죽지 않게 만든 것들

| 상황 | 동작 |
|---|---|
| 시트 조회 실패 | **마지막 성공 값으로 계속 그린다.** 상단에 경고만 뜨고 화면은 살아 있다 |
| SSE 끊김 | 3초 폴링으로 자동 강등. 복구되면 다시 SSE 로 올라간다 |
| 환경변수 누락 | 서버는 뜨고 화면에 무엇이 빠졌는지 표시한다 (트레이스백 대신) |
| 발표장 네트워크 | 차트를 **외부 라이브러리 없이 SVG/CSS 로** 그린다. CDN을 부르지 않는다 |
| 탭 여러 개 | 폴링은 백그라운드 스레드 한 곳에서만. 탭이 늘어도 시트 API 호출은 그대로다 |
| 화면 깜박임 | SSE는 **내용이 실제로 바뀔 때만** 보내고, 카드는 `inquiry_id` 로 요소를 재사용한다. 등장 애니메이션은 새 문의에서만 재생된다 (개발일지 P-12) |

## 알아둘 것

- **`needs_lookup` 은 선택 컬럼이다.** `문의` 시트 U열에 없으면 "분류 축" 카드에서 조회필요 항목만 빠지고 나머지는 정상 동작한다. 추가하려면 U1에 `needs_lookup` 을 넣고 n8n `상태: 승인대기` 노드 매핑에 `{{ $('초안 파싱').first().json.needs_lookup }}` 를 더한다
- **평균 처리 시간은 `타임스탬프`(폼) → `sent_at`** 으로 계산한다. 폼은 한국어 로케일(`2026. 8. 1 오후 3:24:10`), n8n은 ISO 로 쓰는데 양쪽 다 파싱한다. 파싱에 실패한 행은 평균에서 빠지고 KPI에 기준 건수를 함께 표시한다
- **Sheets API 읽기 한도는 분당 60회.** 기본 2초 폴링이면 분당 30회라 여유가 있다
