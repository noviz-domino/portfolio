# AGENTS.md

이 저장소의 모든 프로젝트 지침은 `CLAUDE.md` 하나로 관리한다.
Codex는 작업 시작 전 반드시 `CLAUDE.md`를 읽을 것.
**이 파일에는 프로젝트 지침을 복사하지 않는다** — 과거 이 파일이 `CLAUDE.md`의 낡은 복사본이
되면서, 이미 삭제된 `ReviewScreen.kt`와 `review` 라우트를 참조하는 사고가 있었다.

작업 시작 전 다음 순서로 확인한다.

1. `CLAUDE.md` — 프로젝트 지침 (단일 원본)
2. `AI_WORKLOG.md` — 현재 미커밋 작업과 소유자
3. `git status`
4. `git log --oneline -10`

**위 확인 절차를 마치기 전에는 저장소 파일을 수정·삭제하지 않는다.**
특히 다른 작업자의 미커밋 변경은 소유자를 확인하기 전까지 건드리지 않는다.
