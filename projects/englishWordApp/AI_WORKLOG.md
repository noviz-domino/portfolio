# AI 작업 인수인계

이 파일은 **현재 미커밋 작업만** 기록한다. 완료된 작업의 역사는 `git log`가 보관한다.

운영 규칙:

- 작업을 커밋하면 해당 항목을 **삭제**한다.
- 검증 결과는 커밋 메시지 본문에 `검증: <명령> 성공` 형식으로 남긴다.
- 남은 작업은 항목을 지우기 전에 옮긴다 — **다음 작업자가 해야 할 일**은 `CLAUDE.md`의
  "알려진 이슈 / 미구현"(자동으로 읽히는 유일한 문서), 배경·장기 계획은 `docs/PLAN_v9.md`
  또는 `docs/phase-reports/`.
- 다른 작업자의 미커밋 변경은 소유자를 확인하기 전에는 수정·삭제하지 않는다.
- 항목이 3개를 넘으면 새 작업을 시작하기 전에 커밋부터 할 것.

---

## 진행 중 항목

### 소유자 미확인 — 사용자 환경 변경으로 추정

- **작업자/상태**: 미확인 / 보류
- **미커밋 파일과 소유자**:
  - `.idea/deploymentTargetSelector.xml` — Android Studio가 자동 갱신하는 IDE 상태 파일
  - `app/release/app-release.aab` — 2026-08-14 세션 시작 시점에 이미 수정 상태였음.
    v11(versionCode 11) 서명 빌드로 교체한 뒤 커밋하는 것이 이 저장소의 기존 흐름이다
- **의도**: 불명. Claude/Codex 어느 쪽 작업도 아니다.
- **검증**: 해당 없음
- **남은 작업**: 사용자가 출처를 확인한 뒤 커밋하거나 되돌릴 것.
  `.idea/`는 `.gitignore` 대상으로 옮기는 것도 검토할 만하다.
