# englishWordApp 브랜드 키트

## 콘셉트

앱의 기존 파스텔 카드 UI를 살리면서, 펼친 책 자체가 친구가 된 `Word Buddy` 캐릭터를 대표 이미지로 사용한다. 보라색은 학습의 집중감, 핑크색은 부담 없는 친근함, 크림색은 종이와 단어장을 상징한다.

이미지에는 앱 이름을 넣지 않았다. 스토어 등록 이름을 나중에 바꾸더라도 아이콘과 캐릭터를 그대로 재사용할 수 있고, 실제 문구는 Android 문자열이나 스토어 편집본에서 선명하게 관리할 수 있다.

## 파일 구성

### 앱용

- `app/home-header.png`: 상단 광고 바로 아래 홈 화면 브랜드 헤더. 투명 PNG이며 라이트/다크 모드에서 공용으로 사용한다.
- `app/word-buddy-mascot.png`: 1024×1024 투명 마스코트 원본.
- `app/splash-mascot-768.png`: 스플래시/인트로 중앙 배치용 768×768 투명 PNG.
- `android-res/drawable-nodpi/`: Compose에서 바로 불러올 홈 헤더와 마스코트.
- `android-res/mipmap-*/`: 기기 밀도별 런처 아이콘, 원형 아이콘, 적응형 아이콘 전경.

### Google Play용

- `play-store/app-icon-512.png`: 512×512, 불투명 PNG.
- `play-store/feature-graphic-1024x500.png`: 문구가 포함된 최종 피처 그래픽.
- `play-store/feature-graphic-no-text-1024x500.png`: 앱 이름/문구가 정해진 뒤 다시 편집할 수 있는 무문구 버전.

### 원본과 재생성 자료

- `source/`: 이미지 생성 원본과 확인용 합성 이미지.
- `tools/BrandImageTools.cs`: 규격 변환, 투명 배경 정리, 스토어 문구 합성 도구.
- `PROMPTS.md`: 같은 스타일을 유지해 후속 이미지를 만들 때 사용할 생성 프롬프트.

## 홈 화면 적용 원칙

1. 상단 광고 아래에 132dp 높이의 브랜드 헤더를 둔다.
2. 헤더 왼쪽에는 실제 Compose 텍스트 `오늘도 한 단어씩`, `보고 · 듣고 · 풀며 익혀요`를 표시한다.
3. 오른쪽에는 `home-header.png`의 캐릭터를 배치한다.
4. 메뉴는 기존 2열×3행을 유지하되 타일 높이를 124dp로 제한해 헤더 때문에 화면이 답답해지지 않게 한다.
5. 작은 화면에서는 전체 홈 콘텐츠를 세로 스크롤할 수 있게 한다.
6. 다크 모드는 별도 비트맵을 만들지 않고 투명 헤더와 다크 전용 Material 색상을 사용한다.

## Play 스토어 적용 메모

- 앱 아이콘: `app-icon-512.png`를 사용한다. Play Console이 모서리를 기기별로 마스킹하므로 파일 자체에 둥근 모서리를 추가하지 않았다.
- 피처 그래픽: `feature-graphic-1024x500.png`를 사용한다.
- 휴대전화 스크린샷은 최종 홈 UI를 실제 기기에서 다시 캡처해야 한다. AI로 UI 화면을 재생성하면 한글과 실제 기능 화면이 달라질 수 있으므로, 현재 키트에는 가짜 스크린샷을 넣지 않았다.
- 권장 스크린샷 순서: 홈 → 단어 학습/발음 → 퀴즈 → 오답노트/즐겨찾기.

## 유의사항

`TOEIC`은 ETS의 상표이므로 대표 로고와 피처 그래픽에는 해당 문구를 넣지 않았다. 스토어 제목이나 설명에서 사용할 경우 상표 정책과 오인 가능성을 별도로 확인한다.
