## 참고 — 내부용 (스토어에 올리지 않음)

사용자에게 보이지 않지만 이번 릴리즈에 함께 들어간 변경:

- **`androidx.fragment` 1.1.0 → 1.8.5**: `play-services-ads`가 트랜지티브로 끌어오던 낡은
  버전에 대해 Play Console이 "사용 중인 SDK 버전이 오래됨" 경고를 띄워 명시적으로 상향했다
  (`046b562`). Gradle이 충돌을 최고 버전으로 해석하므로 1.1.0/1.0.0 요청이 모두 1.8.5로 올라간다.
- **`buildFeatures { buildConfig = true }`**: 홈 하단에 `BuildConfig.VERSION_NAME`을 표시하기
  위해 켰다. 이제 버전 갱신 시 `versionCode`/`versionName` 두 줄만 고치면 화면에도 반영된다.
- **홈 하단 앱 정보**: 메뉴 타일과 하단 광고 사이 여백에 버전·제작자·문의 이메일을 흐리게 넣었다.
  광고 바로 위이므로 누를 수 있는 요소는 두지 않았다(오조작 클릭은 AdMob에서 무효 트래픽으로
  처리될 수 있음). 나중에 "오늘의 단어"나 학습 현황 요약으로 바꿀 수 있도록 `HomeFooter()`
  컴포저블로 분리해뒀다.
- **AI 에이전트 협업 문서 구조**: `CLAUDE.md`를 지침 단일 원본으로 확정하고 `AGENTS.md`는
  스텁으로 축소, `AI_WORKLOG.md`(현재 미커밋 작업과 소유자)를 도입했다 (`7cc8595`, `5f319fe`).

### 출시 전 확인이 남은 항목

- **실기기 광고 표시**: 개발 중 스크린샷에서 상하단 배너가 나오지 않은 적이 있었다
  (앱 강제 종료 직후의 로드 타이밍 문제로 추정). 업로드 전에 실기기에서 확인할 것.
- **Play 스토어 스크린샷**: 홈 화면이 전면 개편됐으므로 기존 스크린샷이 낡았다.
  홈 → 단어 학습 → 퀴즈 → 오답노트/즐겨찾기 순으로 재촬영이 필요하다.
- **앱 이름 미확정**: 아이콘과 피처 그래픽에 일부러 글자를 넣지 않았다. 이름이 정해지면
  앱 이름·Play 스토어 제목·피처 그래픽 문구를 함께 정리할 것
  (문구 없는 원본: `docs/brand/play-store/feature-graphic-no-text-1024x500.png`).
