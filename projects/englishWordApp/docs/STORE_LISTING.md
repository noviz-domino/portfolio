# Play 스토어 등록정보 문구 (ko-KR)

Play Console → 사용자 늘리기 → 앱 정보 → **스토어 등록정보**에 넣는 텍스트의 원본이다.
스토어에서 직접 수정했으면 이 파일도 함께 갱신할 것 (다음에 고칠 때 기준이 되는 문서).

버전별 "출시 노트"는 여기가 아니라 `RELEASE_NOTES_v*.md`에 있다.

---

## 앱 이름 (30자 제한)

```
토익 영단어 - 워드버디
```

13자. 대안: `토익 보카 - 워드버디`(12자) — "보카" 검색량을 더 높게 보면 이쪽.

> **이전 이름에서 바꾼 이유**: `토익 영어단어(토익보카,vaca,영단어,영어단어)`는 괄호 안이
> 검색 키워드 나열이라 Google Play 스토어 등록정보 정책의 "제목에 과도한 키워드" 금지에
> 걸릴 소지가 있었다 (`vaca`는 `voca` 오타이기도 했다). 빠진 키워드는 아래 자세한 설명에
> 자연스럽게 녹여 넣었다 — Play 검색은 설명 텍스트도 색인한다.

> **후속 작업**: 런처에 표시되는 이름은 `app/src/main/res/values/strings.xml`의 `app_name`이
> 결정하며 현재 `englishWordApp`이다. 스토어 이름과 맞추려면 앱 코드를 고쳐야 하므로
> 다음 버전에서 반영할 것.

## 간단한 설명 (80자 제한)

```
발음 듣기·퀴즈·오답노트까지, 토익 필수 영단어를 매일 조금씩 확실하게 외워보세요.
```

46자.

## 자세한 설명 (4000자 제한)

```
토익 필수 영단어 1,200여 개를 day1부터 day30까지 나눠, 매일 조금씩 확실하게 외우는 단어 암기 앱입니다.

■ 뜻을 가려두고 스스로 테스트
단어의 뜻이 기본적으로 가려져 있습니다. 먼저 떠올려 본 다음 탭해서 확인하세요. 단어와 뜻이 한꺼번에 보이는 방식과 달리, 실제로 외웠는지 스스로 점검할 수 있습니다.

■ 발음 듣기
단어 옆 스피커를 누르면 발음을 들을 수 있습니다. 카드를 넘길 때마다 자동으로 발음을 들려주는 자동 발음 기능도 있어, 눈으로만 외우지 않고 소리까지 함께 익힐 수 있습니다.

■ 이어서 학습
앱을 껐다 켜도 마지막으로 보던 위치를 기억합니다. 홈 화면의 '이어보기'를 누르면 중단한 지점부터 바로 이어서 학습할 수 있습니다.

■ 즐겨찾기
헷갈리는 단어는 별 아이콘으로 즐겨찾기에 담아두세요. 따로 모아 보고, 즐겨찾기에 담긴 단어만으로 다시 학습하거나 퀴즈를 풀 수 있습니다.

■ 오답노트
'모른다'로 답한 단어와 퀴즈에서 틀린 단어가 오답노트에 자동으로 쌓입니다. 약한 단어만 골라 반복할 수 있어 효율적입니다.

■ 4지선다 퀴즈
day별로, 또는 즐겨찾기·오답노트에 모아둔 단어로 퀴즈를 풀 수 있습니다. 점수와 정답률을 확인하고, 틀린 단어는 오답노트에 자동으로 등록됩니다.

■ 그 밖에
· 단어 순서를 섞어서 외우는 셔플 기능
· day별 학습 진행도와 완료 표시
· 시스템 설정에 따라 자동으로 적용되는 다크 모드
· 회원가입과 로그인 없이 바로 사용

■ 이런 분께 추천합니다
· 토익 점수를 올리려고 단어부터 시작하려는 분
· 두꺼운 토익 보카 책을 끝까지 보지 못하고 덮었던 분
· 출퇴근길이나 이동 중에 짧게 자주 외우고 싶은 분

학습 기록(진행도, 즐겨찾기, 오답노트)은 기기 안에만 저장되며 별도의 서버로 전송되지 않습니다. 앱 내 광고는 Google AdMob으로 제공되며, 광고를 제공하는 과정에서 Google이 광고 식별자 등을 사용할 수 있습니다.

문의: noviz2025@gmail.com
```

991자.

> **⚠️ 개인정보 문구는 임의로 되돌리지 말 것.** 이전 설명에는 "별도의 개인정보 수집이나
> 활용은 없습니다"가 있었으나 **사실과 다르다** — `play-services-ads`(AdMob)가 광고 식별자를
> 사용하므로 "수집 없음"은 허위 진술이고, Play Console의 **데이터 보안** 섹션과 불일치하면
> 반려 사유가 된다. 그래서 "학습 기록은 기기에만 저장" + "광고는 AdMob이 식별자 사용 가능"
> 두 문장으로 나눠 썼다. 실제 구조(로컬 SharedPreferences + AdMob)와 정확히 일치한다.
>
> 데이터 보안 설문도 이에 맞춰 "앱이 기기 또는 기타 ID를 수집함 / 광고 목적"으로
> 신고되어 있는지 확인할 것.

### AI 애셋 선언

Play Console의 "AI 애셋 선언"에서 **"AI를 사용하여 생성 또는 수정한 것으로 애셋 라벨 지정"**을
선택하고, 개별 애셋은 아래대로 구분한다.

- **AI 생성 → 라벨 지정**: 앱 아이콘, 그래픽 이미지 (마스코트 포함 — 이미지 생성 도구로 제작,
  `brand/PROMPTS.md`에 프롬프트 기록)
- **AI 생성 아님 → 라벨 지정 안 함**: 휴대전화 스크린샷 6장 (실기기 `adb` 캡처)
