```
## v10.0 업데이트 안내

이번 업데이트로 앱이 처음 만들었을 때와는 완전히 다른 학습 경험을 제공합니다.

### 📖 학습 화면 개편
- 뜻이 기본적으로 가려져 있고, 탭하면 공개됩니다 — 그동안은 단어와 뜻이 항상 같이 보여서
  스스로 암기했는지 확인할 방법이 없었는데, 이제는 진짜 테스트가 됩니다
- 좌우 스와이프로 단어를 넘기거나, 이전/다음 버튼도 그대로 사용 가능
- 상단에 학습 진행도(예: 12/40)가 표시됩니다
- 원하면 단어 순서를 섞어서(셔플) 학습할 수 있습니다

### 🏠 이어서 학습
앱을 껐다 켜도 마지막으로 보던 위치를 기억해서, 홈 화면에서 바로 이어서 학습할 수 있습니다.

### 🔊 발음 듣기
단어 옆 스피커 아이콘을 탭하면 발음을 들을 수 있습니다. 카드가 넘어갈 때마다 자동으로
발음을 들려주는 기능도 켤 수 있습니다.

### ⭐ 즐겨찾기 / 📝 오답노트
헷갈리는 단어는 즐겨찾기로 표시하고, "모른다"로 답한 단어는 오답노트에 자동으로 쌓입니다.
둘 다 별도 화면에서 모아보고 다시 학습할 수 있습니다.

### 🎯 4지선다 퀴즈
day별로, 또는 즐겨찾기·오답노트에 모아둔 단어로 퀴즈를 볼 수 있습니다. 점수와 정답률을
확인하고, 틀린 단어는 오답노트에 자동으로 등록되어 계속 추적됩니다.

### 🌙 다크 모드
시스템 설정에 따라 자동으로 다크 모드가 적용됩니다.

### 기타

- 전반적인 화면 반응 속도와 안정성 개선
```

## 참고 — 내부용 (스토어에 올리지 않음)
이번 릴리즈는 Java/XML 기반이었던 이전 버전(Play Store 기준 v8)을 Kotlin + Jetpack Compose로
전면 재작성한 결과물이다 (`docs/PLAN_v9.md`, `docs/phase-reports/` 참고). 개발 중간 단계의
버그(아이콘 클릭 안 됨, 광고가 시스템 바 뒤에 깔림 등)는 이번 출시 전에 이미 실기기로 확인하고
고쳤으므로, 사용자 관점에서는 "버그 수정"이 아니라 처음부터 정상 동작하는 새 기능으로 보인다 —
출시 노트에도 그렇게 반영했다.
