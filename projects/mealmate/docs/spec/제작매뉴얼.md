# MealMate 초보자용 직접 제작 매뉴얼
## Git Bash 설치부터 Next.js + Supabase Auth + Gemini + Vercel 배포까지
> 이 문서는 Claude Code를 기다리지 않고 **완전 초보자가 직접 따라 하는 순서**로 작성했습니다. 한 단계씩 진행하고, 각 단계의 확인 결과가 맞을 때만 다음 단계로 넘어가세요.
* * *
## 0\. 완성할 서비스 모습
완성 후 방문자는 로그인 없이 공개 식단 카드를 볼 수 있습니다. 로그인한 회원은 냉장고 재료를 입력해 AI 주간 식단을 만들고, 자신의 식단을 저장하고, 공개 여부를 바꿀 수 있습니다.

사용 기술:
*   Next.js + TypeScript
*   Tailwind CSS
*   Supabase Auth + Database
*   Gemini API 무료 티어
*   Vercel 무료 배포
*   n8n 없음

## 1\. 먼저 설치할 프로그램
### 1-1. Node.js 설치
1. Google 검색창에 `Node.js official download`를 입력합니다.
2. `nodejs.org` 공식 사이트에 들어갑니다.
3. **LTS**라고 표시된 버전을 다운로드합니다.
4. 설치 화면은 기본값으로 계속 진행합니다.
5. 설치가 끝나면 Git Bash를 새로 엽니다.

확인 명령:

```bash
node --version
npm --version
```

둘 다 버전 숫자가 나오면 성공입니다. `command not found`가 나오면 Git Bash를 닫았다가 다시 열고, 그래도 안 되면 Node.js를 다시 설치합니다.
### 1-2. Git 설치
1. Google에서 `Git for Windows official` 검색
2. `git-scm.com` 접속
3. Windows용 Git 다운로드
4. 모든 설치 옵션은 기본값으로 진행
5. Git Bash 실행

확인:

```bash
git --version
```

다음 사이트에 회원가입합니다.
*   GitHub: `github.com`

3. Email이 켜져 있는지 확인
4. Email confirmation 설정을 켭니다.
### 5-3. URL 설정
1. Authentication → URL Configuration
2. Site URL에 일단 `http://localhost:3000` 입력
3. Redirect URLs에 다음 입력


```sql
create extension if not exists pgcrypto;

create table public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  display_name text not null default 'MealMate 사용자',
  created_at timestamptz not null default now()
);

create table public.meal_plans (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  title text not null default '주간 식단',
  ingredients text[] not null default '{}',
  exclusions text[] not null default '{}',
  goal text not null check (goal in ('loss','maintain','bulk','balanced')),
  meals_per_day int not null check (meals_per_day in (2,3)),
  start_date date not null default current_date,
  summary text,
  tips text[] not null default '{}',
  is_public boolean not null default true,
  total_meals int not null default 0,
  done_meals int not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create index meal_plans_public_idx on public.meal_plans (is_public, created_at desc);
create index meal_plans_user_idx on public.meal_plans (user_id, created_at desc);

create table public.meal_days (
  id uuid primary key default gen_random_uuid(),
  plan_id uuid not null references public.meal_plans(id) on delete cascade,
  day_index int not null check (day_index between 1 and 7),
  tip text,
  unique(plan_id, day_index)
);

create table public.meals (
  id uuid primary key default gen_random_uuid(),
  plan_id uuid not null references public.meal_plans(id) on delete cascade,
  day_id uuid not null references public.meal_days(id) on delete cascade,
  user_id uuid not null references auth.users(id) on delete cascade,
  slot text not null check (slot in ('breakfast','lunch','dinner')),
  name text not null,
  used_ingredients text[] not null default '{}',
  needed_ingredients text[] not null default '{}',
  reason text,
  tags text[] not null default '{}',
  is_done boolean not null default false,
  unique(day_id, slot)
);

create table public.shopping_items (
  id uuid primary key default gen_random_uuid(),
  plan_id uuid not null references public.meal_plans(id) on delete cascade,
  user_id uuid not null references auth.users(id) on delete cascade,
  name text not null,
  category text not null default '기타',
  priority text not null check (priority in ('required','recommended','optional')),
  reason text,
  is_bought boolean not null default false,
  sort_order int not null default 0
);

create or replace function public.handle_new_user()
returns trigger language plpgsql security definer set search_path = public as $$
begin
  insert into public.profiles (id, display_name)
  values (new.id, coalesce(new.raw_user_meta_data->>'display_name', 'MealMate 사용자'));
  return new;
end; $$;

create trigger on_auth_user_created
after insert on auth.users
for each row execute procedure public.handle_new_user();

create or replace function public.sync_done_meals()
returns trigger language plpgsql as $$
begin
  update public.meal_plans p
  set done_meals = (
    select count(*) from public.meals m
    where m.plan_id = coalesce(new.plan_id, old.plan_id) and m.is_done
  )
  where p.id = coalesce(new.plan_id, old.plan_id);
  return null;
end; $$;

create trigger meals_sync_done
after insert or update of is_done or delete on public.meals
for each row execute procedure public.sync_done_meals();

alter table public.profiles enable row level security;
alter table public.meal_plans enable row level security;
alter table public.meal_days enable row level security;
alter table public.meals enable row level security;
alter table public.shopping_items enable row level security;

create policy profiles_select_own on public.profiles
for select using (auth.uid() = id);

create policy plans_public_select on public.meal_plans
for select using (is_public = true or auth.uid() = user_id);
create policy plans_insert_own on public.meal_plans
for insert with check (auth.uid() = user_id);
create policy plans_update_own on public.meal_plans
for update using (auth.uid() = user_id) with check (auth.uid() = user_id);
create policy plans_delete_own on public.meal_plans
for delete using (auth.uid() = user_id);

create policy days_select_visible_plan on public.meal_days
for select using (exists (
  select 1 from public.meal_plans p
  where p.id = plan_id and (p.is_public or p.user_id = auth.uid())
));
create policy days_insert_own on public.meal_days
for insert with check (exists (
  select 1 from public.meal_plans p where p.id = plan_id and p.user_id = auth.uid()
));
create policy days_delete_own on public.meal_days
for delete using (exists (
  select 1 from public.meal_plans p where p.id = plan_id and p.user_id = auth.uid()
));

create policy meals_select_visible_plan on public.meals
for select using (exists (
  select 1 from public.meal_plans p
  where p.id = plan_id and (p.is_public or p.user_id = auth.uid())
));
create policy meals_insert_own on public.meals
for insert with check (auth.uid() = user_id);
create policy meals_update_own on public.meals
for update using (auth.uid() = user_id) with check (auth.uid() = user_id);
create policy meals_delete_own on public.meals
for delete using (auth.uid() = user_id);

create policy shopping_select_visible_plan on public.shopping_items
```

```plain
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'

export async function createClient() {
  const cookieStore = await cookies()
  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll()
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            )
          } catch {
            // Server Component에서는 쿠키 설정이 제한될 수 있음
          }
        },
      },
    }
  )
}
```

## 10\. middleware로 로그인 세션 갱신
`middleware.ts`를 프로젝트 루트에 만듭니다.

```plain
import { createServerClient } from '@supabase/ssr'
import { NextResponse, type NextRequest } from 'next/server'

export async function middleware(request: NextRequest) {
  let response = NextResponse.next({ request })
  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() { return request.cookies.getAll() },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value, options }) => {
            request.cookies.set(name, value)
            response = NextResponse.next({ request })
            response.cookies.set(name, value, options)
          })
        },
      },
    }
  )
  await supabase.auth.getUser()
  return response
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)'],
}
```

### 11-1. callback Route Handler
`app/auth/callback/route.ts`

```plain
import { NextResponse } from 'next/server'
import { createClient } from '@/lib/supabase/server'

export async function GET(request: Request) {
  const url = new URL(request.url)
  const code = url.searchParams.get('code')
  const next = url.searchParams.get('next') || '/'

  if (code) {
    const supabase = await createClient()
    const { error } = await supabase.auth.exchangeCodeForSession(code)
    if (!error) return NextResponse.redirect(new URL(next, url.origin))
  }

  return NextResponse.redirect(new URL('/auth?error=callback', url.origin))
}
```

## 12\. 로그인과 회원가입 컴포넌트
### 12-1. SignupForm.tsx
`components/SignupForm.tsx`

```plain
'use client'

import { FormEvent, useState } from 'react'
import { createClient } from '@/lib/supabase/client'

export function SignupForm({ onLogin }: { onLogin: () => void }) {
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [message, setMessage] = useState('')
  const [loading, setLoading] = useState(false)

  async function handleSubmit(e: FormEvent) {
    e.preventDefault()
    setMessage('')
    if (password.length < 8) {
      setMessage('비밀번호는 8자 이상 입력해 주세요.')
      return
    }
    setLoading(true)
    const supabase = createClient()
    const { error } = await supabase.auth.signUp({
      email,
      password,
      options: {
        emailRedirectTo: `${window.location.origin}/auth/callback?next=/auth/confirmed`,
      },
    })
    setLoading(false)
    if (error) {
      setMessage(error.message.includes('already registered')
        ? '이미 가입된 이메일입니다. 로그인 탭을 이용해 주세요.'
        : error.message)
      return
    }
    setMessage('인증 메일을 보냈어요. 이메일 링크를 클릭한 뒤 로그인해 주세요.')
  }

  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <h2 className="text-xl font-bold">회원가입</h2>
      <input required type="email" value={email} onChange={e => setEmail(e.target.value)} placeholder="이메일" className="w-full rounded-xl border p-3" />
      <input required type="password" value={password} onChange={e => setPassword(e.target.value)} placeholder="비밀번호 8자 이상" className="w-full rounded-xl border p-3" />
      {message && <p className="rounded-lg bg-emerald-50 p-3 text-sm">{message}</p>}
      <button disabled={loading} className="w-full rounded-full bg-emerald-700 p-3 font-semibold text-white disabled:opacity-50">
        {loading ? '가입 처리 중...' : '회원가입'}
      </button>
      <button type="button" onClick={onLogin} className="w-full text-sm underline">이미 계정이 있나요? 로그인</button>
    </form>
  )
}
```

### 12-2. LoginForm.tsx
`components/LoginForm.tsx`

```plain
'use client'

import { FormEvent, useState } from 'react'
import { useRouter } from 'next/navigation'
import { createClient } from '@/lib/supabase/client'

export function LoginForm({ onSignup, next = '/' }: { onSignup: () => void; next?: string }) {
  const router = useRouter()
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [message, setMessage] = useState('')
  const [loading, setLoading] = useState(false)

  async function handleSubmit(e: FormEvent) {
    e.preventDefault()
    setMessage('')
    setLoading(true)
    const supabase = createClient()
    const { error } = await supabase.auth.signInWithPassword({ email, password })
    setLoading(false)
    if (error) {
      setMessage(error.message.includes('Email not confirmed')
        ? '이메일 인증 링크를 먼저 클릭해 주세요.'
        : '이메일 또는 비밀번호를 확인해 주세요.')
      return
    }
    router.push(next)
    router.refresh()
  }

  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <h2 className="text-xl font-bold">로그인</h2>
      <input required type="email" value={email} onChange={e => setEmail(e.target.value)} placeholder="이메일" className="w-full rounded-xl border p-3" />
      <input required type="password" value={password} onChange={e => setPassword(e.target.value)} placeholder="비밀번호" className="w-full rounded-xl border p-3" />
      {message && <p className="rounded-lg bg-red-50 p-3 text-sm text-red-700">{message}</p>}
      <button disabled={loading} className="w-full rounded-full bg-emerald-700 p-3 font-semibold text-white disabled:opacity-50">
        {loading ? '로그인 중...' : '로그인'}
      </button>
      <button type="button" onClick={onSignup} className="w-full text-sm underline">계정이 없나요? 회원가입</button>
    </form>
  )
}
```

## 13\. Gemini 공통 모듈
`lib/gemini.ts`

```plain
import { GoogleGenAI } from '@google/genai'

export const MODEL = 'gemini-2.5-flash'

function getAI() {
  if (!process.env.GEMINI_API_KEY) throw new Error('GEMINI_API_KEY is missing')
  return new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY })
}

export async function generateJson({
  systemInstruction,
  contents,
  responseSchema,
}: {
  systemInstruction: string
  contents: string
  responseSchema: unknown
}) {
  const ai = getAI()
  const result = await ai.models.generateContent({
    model: MODEL,
    contents,
    config: {
      systemInstruction,
      temperature: 0.7,
      maxOutputTokens: 8192,
      responseMimeType: 'application/json',
      responseSchema,
      thinkingConfig: { thinkingBudget: 0 },
    },
  })
  const text = result.text
  if (!text) throw new Error('EMPTY_AI_RESPONSE')
  return JSON.parse(text)
}
```

실제 프로젝트에서는 429 재시도와 timeout도 추가합니다. 처음에는 위 코드로 연결 테스트를 하고, 연결 성공 후 재시도 로직을 넣습니다.

## 21\. 자주 발생하는 문제
### `User already registered`
이미 가입된 이메일입니다. 회원가입이 아니라 로그인 탭을 사용하세요. 코드에서 LoginForm과 SignupForm이 분리되어 있는지 확인합니다.
### `Email not confirmed`
메일함·스팸함에서 Supabase 인증 메일을 찾아 링크를 클릭합니다. 로컬 주소와 Vercel 주소가 Supabase Redirect URL에 모두 등록되어 있는지 확인합니다.
### Vercel에서는 로그인 후 다시 로그아웃됨
*   Vercel 환경변수 5개가 모두 등록됐는지 확인
*   Production 환경에 등록했는지 확인
*   Supabase Site URL이 실제 Vercel 주소인지 확인
*   재배포
### 식단 생성이 401
현재 브라우저에 로그인 세션이 없습니다. `/auth`에서 다시 로그인하고, 서버에서 `supabase.auth.getUser()`를 먼저 호출하는지 확인합니다.
### 공개 홈에 비공개 식단이 보임
쿼리에 `.eq('is_public', true)`가 있는지 확인하고, RLS 정책을 끄지 않았는지 확인합니다.
### Gemini JSON 파싱 오류
*   `responseMimeType: application/json`
*   `responseSchema`
*   `safeJson` 또는 JSON parsing
*   maxOutputTokens 8192

을 확인합니다.

### 데스크톱 양옆이 너무 비어 있음
`max-w-md` 같은 모바일 폭 래퍼가 전체 페이지에 적용됐는지 확인합니다. 홈은 `max-w-[1360px] mx-auto px-6`, 카드 영역은 grid를 사용해야 합니다.
