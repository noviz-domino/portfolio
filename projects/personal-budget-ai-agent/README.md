# 개인 예산 관리 AI Agent

자연어로 수입·지출을 기록하고 예산을 관리하는 AI Agent.
Gemini의 **Function Calling**을 이용해, 모델이 사용자의 요청을 이해하고 적절한 Python 도구를 스스로 선택·호출한다.

> 단순한 금융 계산기가 아니라, **실제 기능을 수행하는 Agent**를 만드는 것이 목표다.

```
사용자: "오늘 점심으로 12,000원 썼어"
  → Gemini가 add_transaction 도구를 선택
  → Python 함수가 실행되어 식비 지출로 등록
  → 결과를 받아 사용자에게 자연스럽게 안내
```

---

## ✅ 현재 상태

**전체 10단계 완료.** 자연어 입력 → 도구 호출 → 실행 → 응답까지 실제로 동작한다.

| Phase | 내용 | 상태 |
|---|---|---|
| 1 | 데이터 구조 · 검증 함수 | ✅ 완료 |
| 2 | 핵심 도구 (등록 / 검색 / 수정) | ✅ 완료 |
| 3 | 예산 도구 (설정 / 조회) | ✅ 완료 |
| 4 | JSON 저장 · 불러오기 | ✅ 완료 |
| 5 | Gemini 도구 등록 | ✅ 완료 |
| 6 | Agent loop | ✅ 완료 |
| 7 | 시연 시나리오 검증 | ✅ 완료 |
| 8 | 선택 기능 (삭제 / 로그 / 보고서) | ✅ 완료 |
| 9 | `.py` 모듈 분리 | ✅ 완료 |
| 10 | 문서 정리 | ✅ 완료 |

## 계획된 기능

**필수**
- 자연어로 수입·지출 등록
- 날짜 · 기간 · 카테고리 · 키워드로 거래 검색
- 기존 거래 수정
- 카테고리별 월 예산 설정 및 잔여 한도 조회
- 잘못된 금액 · 날짜 · 거래 ID에 대한 예외 처리
- 검색 결과가 여러 건일 때 임의 선택 대신 사용자에게 재질의
- 도구 호출과 실행 결과를 콘솔에 출력
- 최대 반복 횟수를 둔 Agent loop

**선택**
- 거래 삭제
- JSON 저장·불러오기 (재실행 후 데이터 유지)
- 월별 Markdown 보고서 생성
- 도구 호출 로그 파일

## 설계

전체 설계는 **[기획서.md](기획서.md)** 에 정리되어 있다.

- 데이터 구조 명세 (거래 딕셔너리, 예산 2단계 딕셔너리, JSON 형식)
- 반환 형식 규약 `{ok, data/error, message}` 와 오류 코드 9종
- 도구 함수 7개의 시그니처 · 동작 순서 · 반환 예시
- Gemini 도구 schema 작성 원칙
- Agent loop 의사코드
- 시연 시나리오와 구현 순서 체크리스트

### 주요 설계 포인트

- **모든 도구가 동일한 형식으로 반환** → Agent loop의 결과 처리 코드를 하나로 통일
- **오늘 날짜는 도구가 아닌 시스템 프롬프트로 주입** → 모델이 호출을 누락할 위험 제거
- **검색 결과가 여러 건이면 임의 선택 대신 재질의** → 프롬프트 규칙으로 구현
- **최대 반복 횟수를 둔 Agent loop** → 무한 도구 호출로 인한 비용 폭증 방지
- **사용 금액은 저장하지 않고 매번 계산** → 거래가 수정·삭제되어도 항상 정확

## 실행 방법

```bash
pip install google-genai python-dotenv
```

`.env` 파일을 만들고 API 키를 설정한다 (`.env.example` 참고).

```bash
python agent.py
```

### Windows에서 실행할 때

Windows 콘솔의 기본 인코딩(cp949)이 한글·이모지를 제대로 처리하지 못해, 입력이 깨져
Gemini가 400 에러를 내거나 출력 중 `UnicodeEncodeError`로 프로그램이 죽을 수 있다.
`agent.py` 상단에서 `sys.stdin`/`sys.stdout`을 UTF-8로 재설정해 해결했다 —
별도 설정 없이 `python agent.py`만 실행하면 된다.
