# 금융 문서 RAG Agent

PDF의 근거를 보존하고 답변 실패를 줄이기

2026.10 · 3인 팀 · PDF 전처리, Agent 구조·설정 비교 중심

금융 PDF 23개를 검색해 파일명·쪽과 함께 답하는 RAG Agent입니다. 팀 공동 기획과 구조 논의를 거쳐 각자의 구현을 PR로 합쳤습니다.

## 문제

펼침면과 2단 문서에서 읽기 순서가 섞이고 표·그림 정보가 사라졌습니다. 검색 전에 답변 가능 여부부터 결정하는 Agent는 답할 수 있는 질문까지 거절했습니다.

## 구현과 기여

- 글자 좌표를 이용해 읽기 순서를 복원하고, 표 손실 판정과 재판독 흐름을 만들었습니다. 전처리 결과를 원본 PDF와 나란히 대조했습니다.

- 검색 전의 불필요한 판단 단계를 제거하고 검색 결과를 본 뒤 답변·재검색·되묻기를 고르게 했습니다. 재검색과 재작성 횟수에는 상한을 뒀습니다.

- 청킹, 검색 방식, 검색 개수, 임베딩을 한 번에 하나씩 바꾸며 후보 15개를 비교했습니다. 골든셋 작성·검수에도 참여했습니다.

## 확인한 결과

40문항 구조 비교에서 과다 거절 0.32 → 0.12, 답변 점수 1.03 → 1.40. 별도 180문항 설정 비교에서 답변 점수 1.456 → 1.517. 전처리 기록은 표 191개, 청크 1,508개이며 정답 근거 누락 검사 결과는 0이었습니다.

## 한계

답변 점수는 프로젝트 자체 평가 척도이며 정확도 백분율이 아닙니다. 설정 선택에 사용한 180문항의 결과를 미사용 데이터에 대한 일반화 성능으로 해석하지 않습니다.
