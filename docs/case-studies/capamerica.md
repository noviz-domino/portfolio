# 캡아메리카뱅크

AI 상담을 실제 은행 업무 흐름에 연결하기

2026.11 · 팀 기획 후 개인 구현·고도화

계좌·카드·이체 기능에 자연어 상담과 상품·약관 RAG를 연결한 가상 은행 앱입니다. AI 도구도 사용자와 같은 권한으로 동작하도록 구성했습니다.

## 문제

AI가 재시도한 이체 요청이 중복 실행되거나, 상담 도구가 사용자의 권한을 넘어 돈을 움직이는 상황을 막아야 했습니다. 가짜 모델로 통과한 대화도 실제 Gemini에서는 메시지 형식 차이로 실패했습니다.

## 구현과 기여

- 잔액과 장부 변경을 실행 함수로 모으고 행 잠금과 요청 번호를 적용했습니다. 이체는 승인 대기까지만 만들며, 거래 PIN 승인 API를 AI 도구에서 제외했습니다.

- MCP 도구가 사용자 토큰으로 REST API를 호출하게 해, AI가 DB에 직접 접근하거나 더 큰 권한을 갖지 않도록 했습니다.

- 턴마다 계획을 한 번 세우는 라우터로 실행 흐름을 바꾸고 호출 수와 지연 시간을 비교했습니다. 실제 모델의 메시지 제약을 테스트용 가짜 모델에도 반영했습니다.

- 이후 모바일 웹, 대화 스트리밍, 예산 가드와 카드 보호·혜택 탐색 흐름으로 확장했습니다.

## 확인한 결과

기존 기록의 동일 질문 전후 비교에서 상담 p50 15.0 → 8.2초, p95 28.5 → 16.8초. 별도 21문항 점검은 라우팅 20/21, p50 7.5초였습니다. 서로 다른 평가를 하나의 개선 수치로 합치지 않았습니다.

## 한계

p95 8초 목표는 전후 비교에서 미달했습니다. RAG 38문항은 짧은 데모 약관 기준이며 실제 은행의 상품·고객 데이터에 대한 성능 검증이 아닙니다. 금융 거래는 가상 데이터로 시연합니다.
