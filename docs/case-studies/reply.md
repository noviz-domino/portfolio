# ReplyGate와 운영 경험

평가 결과를 의심하고 실제 사용 흐름까지 확인하기

2026.08 - 11 · 개인 프로젝트

ReplyGate는 정책 문서를 근거로 고객 응대 초안을 만들고 담당자가 Telegram에서 승인해야 메일을 발송하는 자동화입니다.

## 문제

정책 없이 생성한 초안이 환불 기간과 금액을 지어냈습니다. 전체 감정 분류 점수가 올라도 일부 클래스는 전혀 맞히지 못하는 문제가 가려져 있었습니다.

## 구현과 기여

- 정책을 조항 단위로 검색하고 근거 밖 수치를 제한했습니다. 사람 승인 단계를 실제 발송 앞에 연결했습니다.

- 분류 결과를 클래스별로 나눠 확인한 뒤 서로 다른 기준을 두 축으로 분리했습니다. 개선 수치와 함께 남은 실패 사례도 기록했습니다.

## 확인한 결과

ReplyGate 평가 50건에서 승인 가능한 초안 17/50 → 47/50(34% → 94%). 비교 대상은 정책이 없는 초안이며 실제 고객 운영 승인률이 아닙니다.

## 한계

함정 문항에서 근거 없는 답변이 남았습니다. Contest Radar 커리어 코치는 로컬 MVP로, 배포 사이트의 완성 기능으로 소개하지 않습니다.
